## 이 툴의 좋은 점

간단한 주제를 입력하면 선택한 스타일에 맞춰 화면을 만들고, 자막과 목소리까지 포함한 영상을 생성할 수 있어요. 화면을 하나씩 만들고 대사에 맞춰 자막과 소리를 편집하는 작업을 <b>한 번에 진행할 수 있다는 점이 정말 편리해요.</b>

<b>클로드에서 한번에 만들어진 흐름도 괜찮지만 간혹 자동으로 만들어진 스크립트가 내 마음에 들지 않을 수 있어요.</b> 같은 주제라도 설명 순서나 강조하는 내용이 내가 생각한 방향과 달라질 수 있거든요.

흐름을 더 통제하고 싶다면, 평소 쓰는 AI에 정해둔 주제를 전달해 콘텐츠 팩토리에 넣을 입력문을 만들어달라고 하세요. 아래에서 주제만 바꿔 쓰는 요청문을 확인할 수 있어요.

## 기본 사용법 · 3단계

### 1. 힉스필드 접속 → 콘텐츠 팩토리 열기

[힉스필드 바로가기](https://higgsfield.ai/s/higgsfield-content-factory-ig-onji-lab-ycZVKD)에 접속해 로그인한 뒤, 상단 메뉴의 Content Factory(콘텐츠 팩토리)를 열어주세요.

<image source="@/01.jpg">상단 메뉴의 'Content Factory' 또는 홈 화면의 '콘텐츠 팩토리' 카드를 선택해요.</image>

### 2. '여기서 생성하기' 클릭

콘텐츠 팩토리에서 오른쪽 '여기서 생성하기'를 선택해요. 웹사이트에서 바로 만드는 방법이에요.

<image source="@/02.jpg">'Claude에서 생성하기' 옆에 있는 '여기서 생성하기'를 눌러주세요.</image>

### 3. 주제 입력 후 생성

화면 아래에서 원하는 스타일의 '참조로 사용'을 선택해요. 주제를 입력하고 영상 길이를 확인한 뒤, 노란색 '생성하기' 버튼을 눌러주세요.

<image source="@/03.jpg">주제 입력 예시 화면 · 스타일과 30초 길이를 선택한 상태예요. 버튼의 크레딧은 예상치이며 설정에 따라 달라질 수 있어요.</image>

입력 예시:

```txt
기온이 40도를 넘는다면?
```

영상이 완성되면 대사, 자막, 목소리를 확인해보세요. 특히 처음 던진 질문에 끝까지 답하고 있는지 살펴보면 좋아요.

## 인스타그램·틱톡에서 원하는 스타일 가져오기

저는 이 부분이 킥인 것 같아요. 기본 스타일 외에도, 마음에 드는 인스타그램 릴스나 틱톡 영상의 링크를 레퍼런스로 넣고, 레퍼런스 영상의 분위기와 구성, 전개 속도를 참고해 내 주제의 새 영상을 만드는 방법이에요.

### 1. 참고할 영상의 링크 복사하기

인스타그램이나 틱톡에서 원하는 스타일의 영상을 찾아 공유 메뉴에서 링크를 복사해주세요. 내 영상처럼 설명이 중심인 레퍼런스를 고르면 그림체, 자막 배치, 장면 전환을 비교하기 쉬워요.

### 2. 콘텐츠 팩토리에 레퍼런스 넣기

주제 입력창 왼쪽의 '레퍼런스 추가'를 눌러주세요.

<image source="@/04.jpg" />

'TikTok 또는 Instagram 링크 추가하기'를 선택한 뒤, 복사한 링크를 붙여넣고 '계속'을 눌러 화면 안내에 따라 등록해주세요.

<image source="@/05.jpg">릴스·틱톡 링크 입력 화면 · 영상 링크는 이 레퍼런스 입력란에 넣어요.</image>

### 3. 내 주제와 바꾸고 싶은 부분 입력하기

레퍼런스를 적용한 뒤, 주제 입력란에는 내가 만들 주제를 적어주세요. 아래의 AI 요청문으로 만든 최종 입력문을 넣어도 돼요. 영상 길이를 확인하고 '생성하기'를 누르면 됩니다.

레퍼런스에서 참고할 요소와 내 영상에서 바꿀 요소를 함께 적으면 원하는 방향을 더 명확히 전달할 수 있어요.

```txt
주제: 기온이 40도를 넘는다면?

레퍼런스의 손그림 느낌과 빠른 장면 전환을 참고해줘.
배경은 버터색으로, 자막은 짧고 굵은 한국어로 바꿔줘.
대사와 장면 내용은 내 주제에 맞게 새로 구성해줘.
```

<callout>
<b>스타일은 레퍼런스로, 내용은 내 주제로.</b><br />원본의 대사나 캐릭터를 그대로 가져오는 방식이 아니라, 스타일과 전개 방식을 참고하는 기능이에요. 완성 후 원하는 그림체·자막·전환 속도가 반영됐는지 확인해주세요.
</callout>

## 흐름을 좀 더 통제하고 싶다면?

<b>정해둔 주제를 평소 쓰는 AI에 전달해, 콘텐츠 팩토리에 넣을 입력문을 만들어달라고 하세요.</b>

세부 대본을 짜는 단계는 아니에요. 어떤 질문으로 시작하고, 무엇을 설명한 뒤, 어떤 결론으로 끝낼지 큰 흐름만 3줄로 잡아주세요.

<callout>
<b>정해둔 주제 → AI가 흐름 기획 → 만들어준 입력문을 콘텐츠 팩토리에 붙여넣기</b><br />AI에서는 입력문을 만들고, 실제 영상은 힉스필드에서 생성해요.
</callout>

### 1. 평소 쓰는 AI에 아래 요청문 보내기

아래 내용을 복사하고, <b>주제 한 곳만</b> 내가 정한 주제로 바꿔주세요. 설명 순서나 결론을 미리 정하지 않아도 돼요.

```txt
주제: [내가 정한 주제]
이 주제로 30초 설명형 쇼츠를 만들 거야.
도입에서 던질 질문 → 중간에 설명할 핵심 → 마지막 결론, 이 큰 흐름만 짧게 3줄로 잡아줘.
대본이나 장면별 설명은 쓰지 마.
```

예를 들어 첫 줄을 '주제: 기온이 40도를 넘는다면?'으로 바꿔 보내면, AI가 주제와 이야기 흐름을 3줄로 정리해줘요.

### 2. AI가 만든 흐름을 읽고, 필요한 부분만 수정하기

AI가 만든 입력문을 읽고 내가 원한 이야기가 맞는지 확인해주세요. 마음에 들지 않는 부분은 평소 말하듯 수정 요청하면 돼요.

```txt
설명할 핵심을 한 가지로 좁히고, 큰 흐름만 3줄로 다시 잡아줘.
```

사실이나 수치가 들어갔다면 출처도 확인해주세요.

### 3. 완성된 입력문을 콘텐츠 팩토리에 붙여넣기

AI가 만들어준 <b>최종 입력문 전체</b>를 복사해, 콘텐츠 팩토리의 '이런 주제로 영상 만들기…' 입력란에 넣어주세요. 원하는 스타일과 길이를 확인한 뒤 '생성하기'를 누르면 됩니다.

<callout>
힉스필드에 붙여넣는 것은 <b>AI가 만들어준 최종 입력문</b>이에요.<br />위의 '큰 흐름만 짧게 3줄로 잡아줘' 요청은 평소 쓰는 AI 채팅창에 보내주세요.
</callout>

<b>주제 한 줄로 시작하고, 흐름을 더 잡고 싶을 때는 AI가 만들어준 입력문을 활용해보세요.</b>
