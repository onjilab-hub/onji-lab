AI로 내 인스타 콘텐츠 전략을 자동화하는 사이트를 직접 만든 과정을 공유합니다. 아이디어를 말하면 마누스가 전체 과정을 안내해주기 때문에 처음 해보시는 분들도 충분히 따라할 수 있어요.

## 전체 흐름

| 단계 | 작업 |
|---|---|
| 1️⃣ | 내 계정 콘텐츠 전략 보고서 만들기 |
| 2️⃣ | 사이트 아이디어 프롬프트 작성 |
| 3️⃣ | 기획안 수정 + 화면지시서 확인 |
| 4️⃣ | 사이트 키비주얼 만들기 |
| 5️⃣ | 오류 잡기 |
| 6️⃣ | 최종 확인 |

## 1️⃣ 내 계정 콘텐츠 전략 보고서

마누스로 사이트를 만들기 전에, 내 계정의 성공 패턴을 파악하기 위한 성과 보고서를 요청합니다.

```txt
내 Instagram 계정을 연결하세요. 
당신이 나의 개인 AI 콘텐츠 전략가 역할을 하여 매주 월요일 오전 9시에 정기 작업으로 Instagram 성과 보고서를 제공하고, 
다음 주를 위한 완전 최적화된 콘텐츠 계획을 함께 제공해 주기를 바랍니다.

먼저 내 Instagram 커넥터를 활성화하세요. 
연결된 계정이 없다면, 간단히 계정을 연결하라고 제안하세요. 또한 계정을 아직 연결하지 않아도 되고 샘플 데이터를 사용하여 분석할 수 있다는 점을 간단히 언급하세요.

# STEP 1 
1부: 성과 분석
과거 20개 게시물의 데이터를 가져오세요. 각 게시물마다 다음을 보고하세요: 도달, 노출, 참여율, 저장, 공유, 프로필 방문 수, 팔로워 증가. 최고의 성과를 낸 3개의 게시물을 식별하고 계정 평균에 비해 성과가 저조한 게시물을 표시하세요.

분석은 다음과 같이 구성하세요:
- 요약 보고서: 전체 계정 상태와 주간 트렌드 (성장, 안정, 또는 참여 감소)에 대한 간단한 한 문단 요약.
- 최고 성과: 성과가 가장 우수한 게시물 3개 및 성공 요인 (형식, 훅, 시간, 해시태그)에 대한 설명과 더 강화하라는 추천.
- 성과 저조: 성과가 미흡한 게시물과 구체적인 진단 (잘못된 시간, 약한 훅, 과포화된 해시태그, 형식 부적합).
- 사용자 통찰: 팔로워가 가장 활동적인 시간, 선호 콘텐츠 형식 (Reel, 캐러셀, 정적 콘텐츠) 및 주목할 만한 인구학적 변화.

2부: 다음 주 콘텐츠 계획
분석을 바탕으로 다음을 포함한 7일 콘텐츠 캘린더를 생성하세요:
- 요일별 추천 게시물 유형 (Reel, 캐러셀, 정적 콘텐츠, Story)
- 사용자 활동에 따른 최적의 게시 시간
- 게시물별 캡션 초안 및 관련 해시태그 10개
- 이번 주 성과가 좋았던 콘텐츠에서 영감을 받은 테마 또는 훅

스타일리시하고 세련된 슬라이드 데크로 이를 표현하세요.
다음 주 게시물을 미리 준비하고 Manus가 이를 즉시 일정 잡아 게시하도록 원하는지 제안하세요. Instagram 게시물을 바로 준비해 언제든 게시할 수 있도록 만드세요.

# STEP 2 
이 단계가 끝났거나 내가 거부한 경우, 분석 정보를 Google Drive, Notion에 저장하거나, 이메일 또는 Slack을 통해 다른 사람에게 보낼지를 묻습니다. 내가 이 중 하나라도 동의하면 커넥터를 활성화하고 진행하세요. 만약 연결된 계정이 없다면, 간단히 계정을 연결하라고 제안하세요.

1단계가 완료된 후에만 2단계를 수행하세요.
```

## 2️⃣ 사이트 아이디어 프롬프트

마누스에게 원하는 사이트를 설명합니다. 원하는 기능 방향을 구체적으로 적을수록 원하는 결과에 가까운 기획안이 나옵니다. "이러이러한 기능이 필요해"로 시작하면 마누스가 먼저 기획안을 제안하고, 검토 후 승인하면 개발을 시작합니다.

```txt
<콘텐츠 자판기> 웹사이트로 만들어보자.

나 말고도 외부 사용자가 사이트에 접속해서 기능을 사용할 수 있게 만들어야 해.
웹사이트 디자인도 자판기처럼 만들어보자.

내가 생각하는 구조는 이래:
- 음료 자판기처럼 3×3 9개 항목이 자판기 안에 담겨 있는 형태
- 돈 넣는 곳 = 분석할 인스타그램 계정 또는 영상 링크 (여러 개 입력 가능하면 좋겠어)
- 분석 완료 후 버튼을 누르면 원하는 결과물이 뚝딱 나오는 방식
- 버튼은 콘텐츠 종류별로 구분:
  릴스 소재(제목) / 릴스 훅 / 릴스 스크립트 / 카드뉴스 소재 등

이건 내 아이디어니까, 사람들이 실제로 반응할 만한 방향으로 더 디벨롭해줘.
계획 먼저 보고 다음 단계로 넘어가는 방식으로 진행하자.
```

## 3️⃣ 기획안 수정 + 화면 기획서 받기

마누스가 기획안을 제안하면 꼼꼼히 검토하고, 마음에 안 드는 부분은 구체적으로 수정을 요청합니다. 명확하게 지시할수록 좋습니다.

- ✅ 컨셉 변경 요청 → "여러 콘텐츠가 아닌, 릴스 콘텐츠로 좁혀서"
- ✅ 새로운 아이디어 요청 → "기존 게시물 주제 반복 말고 새로운 주제로"
- ✅ 산출물 형식 지정 → "패턴 반영 3개 + 트렌드 1개", "트렌드 리포트 형태로 바로 복사 가능하도록", "어떤 성공 게시물 패턴을 참고했는지 명시해줘"

## 4️⃣ 사이트 키비주얼 만들기

사이트의 첫인상을 결정하는 메인 비주얼을 설정합니다. 원하는 분위기와 색상을 설명하면 마누스가 디자인 방향을 잡아줍니다.

### 1. 첫 사이트 결과물

나쁘진 않지만, 인스타그램의 색감과 톤을 더 살리고 싶어서 수정을 요청했습니다.

### 2. 원하는 디자인 방향 지시

```txt
홈 화면 디자인을 바꿔줘.

[원하는 분위기]
- 자판기 컨셉 — 버튼을 누르면 콘텐츠가 나오는 느낌
- 색상: 인스타그램 감성 (핑크→오렌지→퍼플 그라디언트)
- 폰트: 깔끔하고 현대적인 느낌

[메인 카피]
"이번 주 릴스, 자판기에서 뽑아가세요"

[구성 요소]
- 자판기 이미지 (AI 생성)
- 시작하기 버튼 (크고 명확하게)
- 3단계 프로세스 간략 설명
```

## 5️⃣ 오류 잡기

사이트를 실제로 실행해보면 예상치 못한 오류가 나옵니다. 오류 메시지를 캡처해 마누스에게 붙여넣으면 대부분 바로 수정해줍니다.

| 유형 | 상황 | 해결 방법 |
|---|---|---|
| 데이터 오류 | 실제 계정 데이터가 아닌 샘플 데이터가 들어가 있는 경우 | "실제 데이터로 교체해줘" 요청 |
| UI 오류 | 결과물이 화면에 제대로 표시되지 않는 경우 | 스크린샷 첨부 후 수정 요청 |
| 로직 오류 | 패턴이 제대로 적용되지 않는 경우 | "근거 게시물을 명시해줘" 요청 |
| 계속 안될 때 | 오류를 잡았다고 하지만 계속되는 경우 | "전체 프로세스 다시 검수. 1,2,3단계별 산출물을 먼저 나에게 승인 받고 난 뒤에 완료 처리해줘." |

## 6️⃣ 최종 확인

전체 파이프라인을 처음부터 끝까지 한 번 실행해봅니다.

- [ ] 1단계: 계정 분석 결과에 성공 패턴(훅/썸네일/CTA 공식)이 나오는지
- [ ] 2단계: 트렌드 3개가 최신 내용인지
- [ ] 3단계: 릴스 4개 + 7일 캘린더가 나오는지
- [ ] 각 릴스 카드에 스크립트 초안이 포함되어 있는지
- [ ] 근거 게시물이 실제 내 계정 데이터 기반인지
