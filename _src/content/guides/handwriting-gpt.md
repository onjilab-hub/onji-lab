사진 한 장만 올리면 GPT가 감성 손글씨 + 낙서 스타일로 꾸며주는 프롬프트입니다. 공통 프롬프트와 무드별 옵션 프롬프트도 정리해두었으니 저장해두고 필요할 때마다 복붙해서 사용하세요!

## ✨ 사용 방법

1. ChatGPT 이미지 기능에서 사진 업로드
2. 아래 공통 프롬프트 복붙
3. (더 잘 뽑으려면) 사진 종류별 옵션 한 줄 추가
4. 생성하면 끝

## 📌 공통 프롬프트

```txt
업로드한 사진을 메인 기준 이미지로 사용해줘.
사진 속 인물, 동물, 사물, 배경, 분위기를 자연스럽게 분석한 뒤 실제 요소에 맞춰 감성적으로 꾸민 결과물을 만들어줘.

세로형 3:4 비율.

사진에 보이는 각 요소를 관찰한 뒤, 대상에 어울리는 손그림 주석과 손글씨 메모를 자연스럽게 추가해줘.

스타일 가이드:
- 흰 펜으로 직접 그린 듯한 손그림 선
- 피사체 외곽선은 점선으로, 대상과 살짝 떨어진 여백을 두고 표현
- 화살표, 강조선, 움직임 표현선 추가
- 한글 손글씨 메모
- 반짝임, 하트, 작은 별은 은은하게만 추가
- 실제 사진 위에 감성 낙서한 느낌
- 인스타그램 스토리풍, 잡지 메모풍

중요:
사진 원본의 포즈, 구도, 배경은 유지하고 자연스럽게 완성해줘.
```

## 🎨 사진 종류별 옵션 프롬프트

### 💑 커플 사진

```txt
담백하고 설레는 분위기로 꾸며줘.
두 사람의 거리감, 시선, 손동작을 강조해줘.
```

### ✈️ 여행 사진

```txt
설렘과 여유가 느껴지는 분위기로 꾸며줘.
풍경, 하늘, 길, 장소 무드를 강조해줘.
```

### 🐶 강아지 사진

```txt
귀엽고 사랑스러운 분위기로 꾸며줘.
귀, 꼬리, 발걸음, 눈빛을 강조해줘.
```

### ☕ 카페 사진

```txt
조용하고 세련된 분위기로 꾸며줘.
커피, 창가 빛, 테이블 소품, 공간 무드를 강조해줘.
```

### 🌿 일상 사진

```txt
잔잔하고 따뜻한 분위기로 꾸며줘.
햇살, 걸음, 평범한 순간의 무드를 강조해줘.
```

### 🫶 우정 사진

```txt
유쾌하고 자연스러운 분위기로 꾸며줘.
함께 웃는 순간, 장난치는 포인트, 친밀한 무드를 강조해줘.
```

### 👶 아기 사진

```txt
포근하고 사랑스러운 분위기로 꾸며줘.
작은 손, 발, 표정, 귀여운 행동과 성장 기록 느낌을 강조해줘.
```
