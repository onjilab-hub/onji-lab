## 01. 캡컷 CapCut

🔗 [캡컷 바로가기](https://www.capcut.com/)

<b>💰 유/무료 안내</b>

- 기본 편집 기능은 <b>무료</b>
- 아담 등 인기 AI 목소리는 <b>캡컷 Pro 구독 필요</b> (월 약 19,800원~)
- 무료 버전에도 일부 기본 목소리는 있지만, 자주 들리는 익숙한 목소리는 대부분 유료

<b>📋 사용법</b>

<image source="@/01.jpg" />

1. <b>모바일 앱</b>에서 캡컷 실행 후 새 프로젝트 생성
2. 편집 화면 하단 메뉴에서 <b>텍스트 → 텍스트 음성 변환(TTS)</b> 선택
3. 원하는 목소리 선택 (성별·스타일·언어 필터 활용)
4. 텍스트 입력창에 읽힐 내용 입력
5. 영상 내보내기 시 음성 포함되어 자동 다운로드

<callout>
아담, 링아나운서, 소심한개구리 등 익숙한 목소리는 캡컷 모바일 앱에서만 적용할 수 있었어요. PC에서는 안 보이더라고요. 계정마다 조금씩 다를 수 있습니다!
</callout>

## 03. 일레븐랩스 ElevenLabs

🔗 [일레븐랩스 바로가기](https://elevenlabs.io/)

<b>💰 유/무료 안내</b>

- 무료 플랜: <b>매월 10,000 크레딧 제공 = 약 10분 분량</b>
- 내 목소리 학습(Voice Clone)은 유료 플랜에서만 가능
- 더 많은 생성량·클론 개수가 필요하면 Starter 플랜(월 $6~)으로 업그레이드

<b>📋 사용법 — AI 목소리</b>

1. 사이트 접속 후 회원가입 / 로그인
2. Text to Speech 메뉴 선택

<image source="@/07.jpg" />

3. 목소리 라이브러리에서 원하는 보이스 선택

<div class="pair"><img src="@/08.jpg" alt="" loading="lazy"><img src="@/09.jpg" alt="" loading="lazy"></div>

<image source="@/10.jpg" />

4. 텍스트 입력 후 Generate 클릭

<image source="@/11.jpg" />

5. 다운로드 버튼으로 MP3 저장

<image source="@/12.jpg" />

<b>📋 사용법 — 내 목소리 학습</b>

1. Voices → Add Voice → Instant Voice Clone 선택
2. 본인 목소리 녹음 파일 업로드 (1분 이상 권장)
3. 학습 완료 후 내 보이스 라이브러리에 저장됨
4. 이후 TTS 생성 시 내 목소리로 선택해서 사용

## 04. 구글 AI 스튜디오

🔗 [구글 AI 스튜디오 바로가기](https://aistudio.google.com/)

<b>💰 유/무료 안내</b>

- <b>완전 무료</b> — 구글 계정만 있으면 별도 결제 없이 사용 가능
- 한국어도 되지만 기본 목소리가 무난한 편이라 나레이션·정보 전달용 콘텐츠에 잘 맞아요

<b>📋 사용법</b>

1. 구글 계정으로 AI 스튜디오 접속 → Speech and Music 선택

<image source="@/14.jpg" />

3. Mode 설정에서 Single-Speaker audio 선택 후 목소리 스타일 선택 (Puck, Charon, Kore 등)

<image source="@/15.jpg" />

4. 텍스트 입력 후 실행
