<b>MCP 연결 → 영상 업로드 → 명령어 입력 → 효과가 들어간 영상</b><br />인물 뒤에 뜨는 글자, 말에 맞춰 움직이는 자막, 숫자 그래프까지. 클로드에 힉스필드를 연결하고, 원하는 효과를 명령어로 요청해보세요.
</callout>

<b>Claude와 Higgsfield를 연결해 기존 영상에 효과를 넣는 방법</b>을 정리했어요.

<b>클로드가 요청을 이해하고 힉스필드의 도구를 호출하는 방식</b>이에요. MCP는 둘을 연결해주는 통로라고 생각하면 됩니다. 아래 효과 명령어는 <b>이미 만들어둔 영상을 편집하는 용도</b>이므로, 먼저 말하는 영상 하나를 준비해주세요.

## ✅ 시작 전 준비물

1. Claude 계정
2. [Higgsfield 계정](https://higgsfield.ai/s/higgsfield-commands-in-claude-ig-onji-lab-KyCGTL) — MCP 이용이 가능한 구독 또는 체험 상태
3. 효과를 넣을 <b>대사가 포함된 영상</b>
4. 화면에 표시할 단어·이름·숫자 — 순위표라면 항목과 분류 기준도 준비

<callout>
<b>체험과 비용은 연결 화면에서 확인해주세요.</b><br />신규 사용자 대상 <b>MCP 3일 무료 체험</b> 가능하나, 계정·시점에 따라 표시되는 혜택이 달라질 수 있어요. 신청 화면에서 대상 여부, 카드 등록, 제공 크레딧과 체험 종료 후 유료 전환 조건을 확인해주세요.
</callout>

## ✅ 제작 순서 한눈에 보기

| 단계 | 할 일 |
| --- | --- |
| STEP 1 | 힉스필드 MCP 연결 페이지 열기 |
| STEP 2 | 클로드에 커넥터 추가 → 계정 연결 |
| STEP 3 | 연결 확인 → 원본 영상 업로드 |
| STEP 4 | 원하는 효과 명령어 입력 |
| STEP 5 | 크기·위치·타이밍 수정 |
| STEP 6 | 완성 영상 저장 → 릴스에 사용 |

## STEP 1. 힉스필드 MCP 연결 페이지 열기

1. 👉 [Higgsfield MCP 바로가기](https://higgsfield.ai/s/higgsfield-commands-in-claude-ig-onji-lab-KyCGTL)에 접속해요.
2. 연결할 앱으로 <b>Claude</b>를 선택해요.
3. 화면의 <b>Connect to Claude / 연결 안내</b>를 확인해요.
4. 아래 MCP 서버 주소를 복사해요.

<b>📋 연결할 MCP 서버 주소</b>

```txt
https://mcp.higgsfield.ai/mcp
```

💡 위 주소는 <b>클로드의 커넥터 설정에 붙여넣는 주소</b>예요. 브라우저에서 주소만 여는 것으로 연결이 끝나지는 않아요.

## STEP 2. 클로드에 커넥터 추가 → 계정 연결하기

1. [Claude](https://claude.ai/)에 로그인해요.
2. <b>Customize → Connectors</b>를 열어요. 화면에 따라 <b>설정 → 커넥터</b>로 보일 수 있어요.
3. <b>+ Add → Add custom connector</b>를 선택해요.
4. 이름과 주소를 아래처럼 입력해요.
5. 추가 후 <b>Connect</b>를 누르고, 열리는 Higgsfield 창에서 로그인·접근 허용을 진행해요.
6. 클로드로 돌아와 <b>Higgsfield가 연결됨 상태인지</b> 확인해요.

| 입력 항목 | 넣을 내용 |
| --- | --- |
| 이름 | Higgsfield |
| 서버 URL | <code>https://mcp.higgsfield.ai/mcp</code> |

<callout>
<b>API 키를 따로 발급할 필요는 없어요.</b><br />이 가이드는 클로드 웹·데스크톱의 MCP 커넥터 방식이에요. 팀 계정에서 커넥터 추가 메뉴가 보이지 않으면 관리자 권한이나 조직 설정을 확인해주세요.
</callout>

## STEP 3. 연결 확인 → 원본 영상 업로드하기

<b>① 현재 대화에서 Higgsfield 켜기</b>

새 대화를 열고 입력창의 <b>+ 메뉴 → Connectors</b>에서 Higgsfield가 켜져 있는지 확인해요. 메뉴 이름과 위치는 클로드 버전에 따라 달라질 수 있어요.

<b>📋 연결 확인 요청문</b>

```txt
Higgsfield 도구를 사용해서 내 현재 크레딧 잔액을 확인해줘.
아직 이미지나 영상은 생성하지 마.
```

<b>② 편집할 영상 올리기</b>

💡 처음에는 <b>한 사람이 정면을 보고 말하는 짧은 영상</b>이 편해요. 인물 뒤 텍스트나 인물 외곽선 효과를 쓰려면 얼굴과 어깨가 잘 보이는 구도를 준비해주세요.

## STEP 4. 원하는 효과 명령어 입력하기

<b>명령어 + 화면에 넣을 내용 + 효과가 나올 시점</b>을 함께 적으면 원하는 결과를 설명하기 쉬워요. 아래 예시의 이름·문구·숫자는 내 영상에 맞게 바꿔주세요.

### 📌 명령어 7개 한눈에 보기

| 명령어 | 만들어주는 효과 | 함께 알려주면 좋은 것 |
| --- | --- | --- |
| <code>/tier-list</code> | 항목이 등급별로 들어가는 티어표 | 표 제목, 등급, 항목, 등장 시점 |
| <code>/text-behind</code> | 인물 뒤로 겹쳐 보이는 큰 글자 | 표시할 단어, 시작 대사 또는 시간 |
| <code>/captions</code> | 말에 맞춰 따라오는 자막 | 언어, 스타일, 강조색 |
| <code>/glass-graph</code> | 시작값에서 끝값으로 변하는 그래프 | 제목, 시작값, 끝값 |
| <code>/freeze-frame</code> | 인물을 강조하는 정지 화면·외곽선·이름표 | 이름, 짧은 소개, 시작 시점 |
| <code>/over-the-shoulder</code> | 인물 어깨 뒤로 배치되는 전·후 비교 카드 | 전·후 값과 각각의 설명 |
| <code>/grade-wipe</code> | 색감 보정 전·후를 보여주는 와이프 전환 | 시작 시점, 전·후 라벨 |

<b>👇 필요한 항목을 펼쳐서 복사하세요.</b>

<toggle>
📊 /tier-list — 티어표 만들기

<b>어떤 효과인가요?</b><br />툴이나 항목이 S·A·B처럼 지정한 줄에 순서대로 들어가는 표예요.

<b>📋 복사할 요청문</b>

```txt
/tier-list

업로드한 영상에 티어표를 넣어줘.
표 제목: 내가 자주 쓰는 AI 툴

S: [가장 자주 쓰는 툴 이름]
A: [자주 쓰는 툴 이름]
B: [가끔 쓰는 툴 이름]

분류 기준은 성능 순위가 아니라 나의 사용 빈도야.
대사에서 각 이름을 말하는 시점에 해당 줄로 등장시켜줘.
원본 음성은 유지해줘.
```

💡 <b>대사에서 앱 이름을 모두 읽지 않아도 돼요.</b> 그럴 때는 "1초부터 아래 순서대로 등장시켜줘"처럼 시간을 직접 지정해주세요. 한 줄에는 최대 4개, 전체에는 최대 12개 항목을 넣을 수 있어요. 로고를 정확히 쓰려면 이미지도 함께 제공해주세요. 로고를 찾지 못한 항목은 글자로 표시될 수 있어요.
</toggle>

<toggle>
🔤 /text-behind — 인물 뒤에 큰 글자 넣기

<b>어떤 효과인가요?</b><br />글자 일부가 인물에게 가려지면서, 인물 뒤 공간에 놓인 것처럼 보여요.

<b>📋 복사할 요청문 예시</b>

```txt
/text-behind

업로드한 영상에서 "AI에게 시키세요"라고 말하는 순간,
인물 뒤에 "AI"를 크게 보여줘.
흰색 글자로 약 2초 동안 표시해줘.
원본 음성은 유지해줘.
```

💡 긴 문장보다 <b>짧은 단어 하나</b>로 시작해보세요. 타이밍이 다르면 "영상 시작 1초에 나타나게 해줘"처럼 수정할 수 있어요.
</toggle>

<toggle>
💬 /captions — 말에 맞춰 따라오는 자막 넣기

<b>어떤 효과인가요?</b><br />영상 속 말을 인식해 자막을 만들고, 발화 시점에 맞춰 보여줘요.

<b>📋 복사할 요청문 예시</b>

```txt
/captions

업로드한 영상의 한국어 대사를 그대로 자막으로 만들어줘.
classic 스타일로 적용해줘.
강조색은 민트색으로 하고,
얼굴을 가리지 않는 화면 하단에 배치해줘.
원본 음성은 유지해줘.
```

💡 지원하는 자막 스타일에는 <b>spotlight · cascade · classic</b>이 있어요. 완성 후 툴 이름과 고유명사가 제대로 적혔는지 확인해주세요.
</toggle>

<toggle>
📈 /glass-graph — 숫자가 올라가는 그래프 넣기

<b>어떤 효과인가요?</b><br />시작값과 끝값을 넣으면 숫자 변화가 보이는 그래프 카드가 만들어져요.

<b>📋 복사할 요청문 예시</b>

```txt
/glass-graph

업로드한 영상에서 "0%였다가 80%"라고 말하는 부분에
숫자 변화 그래프를 넣어줘.

제목: 사용률 · 예시
시작값: 0%
끝값: 80%
표시 시간: 약 3초
강조색: 민트색

얼굴을 가리지 않게 배치하고 원본 음성을 유지해줘.
```

💡 <b>0% → 80%는 효과를 설명하기 위한 예시</b>예요. 실제 콘텐츠에서는 확인한 수치로 바꾸고, 숫자와 단위가 대사·자막·그래프에서 일치하도록 해주세요.
</toggle>

<toggle>
🙋 /freeze-frame — 인물 소개 효과 넣기

<b>어떤 효과인가요?</b><br />잠깐 멈추는 화면에 인물 외곽선과 이름표가 들어가고, 배경이 흑백으로 바뀌며 인물이 강조돼요.

<b>📋 복사할 요청문 예시</b>

```txt
/freeze-frame

업로드한 영상에서 "온지랩입니다"라고 말하는 순간
인물을 강조하는 소개 효과를 넣어줘.

이름: 온지랩
짧은 소개: AI 활용 튜토리얼
표시 시간: 약 2.5초

원본 음성은 유지해줘.
```

💡 이름과 소개는 짧게 적어주세요. 효과가 끝나면 재생이 이어지므로 대사와 화면이 자연스럽게 연결되는지 확인해요.
</toggle>

<toggle>
↔️ /over-the-shoulder — 전·후 비교 카드 넣기

<b>어떤 효과인가요?</b><br />인물 어깨 뒤에 비교 카드가 나타나, 작업 전후의 차이를 보여줘요.

<b>📋 복사할 요청문 예시</b>

```txt
/over-the-shoulder

업로드한 영상에서 "전에는 0개였지만"이라고 말하는 부분에
전·후 비교 카드를 넣어줘.

이전 라벨: 편집 전
이전 값: 효과 0개
이후 라벨: 편집 후
이후 값: 효과 3개

약 3초 동안 표시하고 원본 음성은 유지해줘.
```

💡 숫자뿐 아니라 짧은 비교 문구도 사용할 수 있어요. <b>비교 값은 실제 영상 내용에 맞춰</b> 바꿔주세요.
</toggle>

<toggle>
🎨 /grade-wipe — 색감 보정 전·후 보여주기

<b>어떤 효과인가요?</b><br />밝은 빛이 화면을 지나가며 보정된 색감이 드러나는 효과예요.

<b>📋 복사할 요청문 예시</b>

```txt
/grade-wipe

업로드한 영상에서 "색감은 이렇게 바꿔볼게요"라고 말하는 순간
색감 보정 전·후를 보여주는 와이프 전환을 넣어줘.

이전 라벨: 원본
이후 라벨: 보정 후
전환 시간: 약 3초

원본 음성은 유지해줘.
```

💡 정해진 보정 스타일을 보여주는 효과예요. 완성 후 피부색이 자연스러운지 확인해주세요.
</toggle>

<b>처음에는 자막이나 인물 뒤 텍스트 하나부터 해보세요.</b> 원하는 효과가 나온 다음 크기와 타이밍을 맞추면, 내 콘텐츠에 어울리는 편집으로 만들어갈 수 있어요.
