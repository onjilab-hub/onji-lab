AI 영상은 트렌드가 빠르게 바뀌지만, 영상 포맷은 어느 정도 패턴화된 것 같아요. 그간 꾸준히 조회수가 잘 나왔던 <b>5가지 AI 영상 포맷별 이미지 / 영상 프롬프트</b>를 정리했습니다.

포맷마다 응용할 수 있는 템플릿을 넣었고, 그 아래에 실제로 사용한 예시 프롬프트를 함께 넣어두었어요.

## 사용 방법

1. 이미지 툴에서 <b>이미지 프롬프트</b>로 영상 스타트 프레임을 만듭니다. (저는 GPT Image 2 사용)
2. 영상 툴에서 <b>영상 프롬프트</b>를 넣어 짧은 영상으로 확장합니다. (저는 Kling 사용)
3. 템플릿 안의 <b>[캐릭터] / [상황] / [장소] / [소재]</b>만 바꿔도 다른 버전으로 쉽게 응용할 수 있어요.

<callout>
원하는 방향의 레퍼런스 이미지를 같이 첨부하면 훨씬 좋은 결과물이 나와요.
</callout>

## 1. 동물 x 요리 애니메이션

### 이미지 프롬프트 템플릿

```txt
[스타일]로 그린 장면이다.
[공간]에서 [동물 캐릭터]가 [요리명]을 만들고 있다.
[요리명]은 [조리도구] 안에서 [상태]이며, [재료명]의 질감과 윤기가 디테일하게 표현되어 있다.
[시간대/조명]이 공간을 비추고, 전체적으로 [분위기]가 느껴지는 정지된 한 장면.
```

### 영상 프롬프트 템플릿

상황이나 움직임을 묘사하고 카메라 구도를 결정합니다.

```txt
[동물 캐릭터]가 [상황] 속에서 [요리명]을 [조리도구]로 천천히 [젓는다/뒤집는다/섞는다].
동작이 이어질 때마다 [재료명]이 자연스럽게 움직이고, [요리 상태]가 디테일하게 표현된다.
캐릭터는 중간중간 [표정/리액션]을 보이며, 카메라는 [구도]로 고정된다.
[조명/공간] 아래 [분위기]가 이어지는 짧은 요리 애니메이션 영상.
```

### 실제 사용 예시

<image source="@/01.jpg">스타트 프레임</image>

```txt
섬세한 선화와 사실적인 조명이 특징인 일본 애니메이션 스타일로 그린 장면이다. 아늑한 가정집 부엌에서 된장찌개가 냄비 안에서 보글보글 끓고 있다. 저녁 시간대의 따뜻한 조명이 부엌 창문으로 은은하게 들어오고, 냄비에서 피어오르는 김이 부드럽게 흩어진다. 찌개 속 두부와 애호박, 된장의 질감과 윤기가 디테일하게 표현되어 있다. 잔잔하고 감성적인 분위기, 따뜻한 색감의 정지된 한 장면.
```

```txt
친칠라 캐릭터가 된장찌개를 국자로 천천히 젓다가, 옆에 놓인 잘린 고추를 집어 된장찌개에 넣는 상황이다. 국자가 냄비 안을 부드럽게 휘저을 때마다 두부와 애호박이 국물 속에서 흔들리며 자리를 바꾼다. 냄비에서는 김이 계속 모락모락 피어오르고, 국물이 보글보글 끓어오르며 잔잔하게 출렁인다. 캐릭터는 고추를 넣은 뒤 카메라를 바라보며 뿌듯한 표정으로 살짝 웃는다. 카메라는 냄비와 캐릭터를 함께 담는 구도로 고정되어 있다. 따뜻한 창가 조명 아래 아늑하고 정겨운 분위기가 이어진다.
```

## 2. 질감이 느껴지는 ASMR 영상

### 이미지 프롬프트 템플릿

```txt
[배경/공간]에서 [소재]를 촬영한 장면이다.
[신체 부위/도구]가 [소재]에 닿은 순간을 포착했고, 닿은 자리 주변으로 [눌림/갈라짐/파문/늘어남] 디테일이 보인다.
카메라는 [접촉 지점]에 가깝게 클로즈업한다.
[조명/색감] 아래 [분위기]가 느껴지는, 질감이 도드라지는 정지된 한 장면. 세로 비율 9:16.
```

### 영상 프롬프트 템플릿

강조하고 싶은 질감, 움직임, 소리를 자세하게 작성해주세요.

```txt
[물체] 의 [질감],[움직임], [소리]를 강조한 ASMR 영상  
[신체 부위/도구]가 [소재]를 천천히 [누른다/자른다/밟는다/깨뜨린다].
동작이 이어질 때마다 [소재]가 [눌리고/갈라지고/출렁이고/복원되는] 움직임을 보인다.
카메라는 [앵글]에서 [대상]을 따라 부드럽게 이동한다.
[소재]의 [광택/탄성/질감]과 [소리 표현]을 강조한, 느린 움직임의 ASMR 영상.
```

### 실제 사용 예시

<image source="@/02.jpg">스타트 프레임</image>

```txt
몽환적인 안개와 부드러운 빛망울이 감도는 신비로운 공간에서, 반투명 젤리 재질로 만들어진 계단을 촬영한 사진이야. 계단은 파스텔 톤(연보라, 연핑크, 민트) 그라데이션으로 빛이 은은하게 비쳐. 맨발이 계단 한 칸을 막 밟아 표면이 말랑하게 눌리고 출렁이는 순간을 포착했고, 발이 닿은 자리 주변으로 젤리 표면에 파문처럼 눌림 자국이 퍼지는 디테일을 살려줘. 카메라는 발과 계단이 맞닿는 지점에 가깝게 클로즈업했어. 조명은 파스텔 네온과 부드러운 백라이트로 신비로운 분위기를 만들어줘. 세로 비율(9:16)로 만들어줘.
```

```txt
젤리의 촉촉한 광택, 탱글한 흔들림, 부드러운 쫀득 ASMR 소리를 강조. 맨발의 여성이 투명한 젤리 계단을 천천히 오른다.발이 닿을 때마다 젤리 계단이 말랑하게 눌리고 다시 복원된다.카메라는 낮은 각도에서 발과 계단을 따라 부드럽게 위로 이동한다.차분하고 몽환적인 실내 분위기, 느린 움직임
```

## 3. 사물이 캐릭터처럼 말하는 영상

### 이미지 프롬프트 템플릿

```txt
[애니메이션 화풍 스타일]로 표현한 장면이다.
[장소]에 놓인 [사물]에 [스타일] 눈코입과 팔(필요하면 다리까지)이 달려 있다.
표정은 [표정/성격]이 느껴지고, 카메라는 [앵글]에서 [사물]을 가깝게 담는다.
배경에는 [주변 사물/공간 요소]가 흐릿하게 보인다.
[분위기]가 느껴지는 정지된 한 장면.
```

### 영상 프롬프트 템플릿

```txt
[장소]에 놓인 [사물]이 [스타일] 눈코입을 움직이며 말을 한다.
"[대사]"라고 [말투/감정]으로 말하며 [제스처/행동]을 한다.
카메라는 [앵글]에서 고정된 채 [사물]을 가깝게 담는다.
[조명/공간] 아래 [분위기]가 이어지고, 자연스러운 표정 변화와 입 모양 중심의 짧은 영상.
```

### 실제 사용 예시

<image source="@/03.jpg">스타트 프레임</image>

```txt
편의점 냉장 진열대에 놓인 바나나우유에 픽사스타일 눈코입과 팔까지 달려있다. 표정은 여유롭고 당당한 얼굴로, 살짝 웃고 있다. 카메라는 정면에서 눈높이로 바나나우유를 가깝게 담는다. 편의점 특유의 형광 조명과 차가운 냉장 진열대 분위기, 배경은 흐릿하게 다른 유제품들이 보인다. 코믹하고 능청스러운 느낌의 정지된 한 장면.
```

```txt
편의점 냉장 진열대에 놓인 바나나우유가 픽사스타일 눈코입을 움직이며 말을 한다. "저 유통기한은 지났어요. 근데 소비기한은 아직 남았거든요?"라고 능청스럽고 여유로운 표정으로 말하며 살짝 으쓱하는 제스처를 한다. 카메라는 정면 눈높이에서 고정된 채 바나나우유를 가깝게 담는다. 편의점 형광 조명 아래 차분하고 코믹한 분위기, 자연스러운 입 모양과 표정 변화 중심의 짧은 영상.
```

## 4. 미니어처 세계관

### 이미지 프롬프트 템플릿

```txt
[배경/공간]에서 [거대한 대상] 위/옆에 손바닥만 한 [미니어처 캐릭터]들이 있다.
캐릭터들은 [행동]을 하고 있으며, [소품/오브젝트]가 장면의 중심에 있다.
배경은 [공간 분위기]이고, 캐릭터들은 작지만 [질감/스타일]이 느껴진다.
사실적이지만 아기자기한 정지된 한 장면.
```

### 영상 프롬프트 템플릿

```txt
[거대한 대상] 위/옆에서 [미니어처 캐릭터]들이 [상황] 속에서 [행동]을 한다.
[상황 전개]가 일어나고, 캐릭터들은 [표정/리액션]을 보인다.
카메라는 [구도]로 고정되어 [대상과 캐릭터]를 가깝게 담는다.
[영상 길이] 분량의 짧고 경쾌한 미니어처 세계관 영상.
```

### 실제 사용 예시

<image source="@/04.jpg">스타트 프레임</image>

```txt
집 안 거실에서 사람의 손가락 위에 미니어처 캐릭터 두 마리가 올라가 있다. 둘은 작은 장난감 공을 사이에 두고 서로 잡아당기며 장난치는 중이다. 캐릭터들은 장난감처럼 작지만 사실적인 털과 질감을 가지고 있다. 배경은 따뜻한 조명의 아늑한 거실. 사실적이고 아기자기한 정지된 한 장면.
```

```txt
사람의 손가락 위에서 미니어처 캐릭터 두 마리가 작은 장난감 공을 두고 서로 잡아당기며 장난치는 상황이다. 장난치다가 장난감 공이 아래로 떨어진다. 두 캐릭터는 서로를 마주 보며 당황한 표정을 짓는다. 카메라는 손가락과 캐릭터를 가깝게 담는 고정된 구도. 5초 분량의 짧고 경쾌한 움직임.
```

## 5. 루프형 애니메이션

### 이미지 프롬프트 템플릿

```txt
[스타일]로 그린 장면이다.
[장소]에서 [캐릭터]가 [반복 가능한 행동]을 하고 있다.
[움직임의 흔적]이 자연스럽게 표현되어 있고, 배경에는 [환경 요소]가 펼쳐져 있다.
밝고 생동감 있는 분위기, 루프 영상의 시작 프레임처럼 보이는 정지된 한 장면.
```

### 영상 프롬프트 템플릿

캐릭터를 같은 위치에 두거나 첫 프레임과 마지막 프레임을 같은 이미지로 고정해야 자연스러워요.

```txt
[캐릭터]가 [장소]에서 [반복 가능한 행동]을 계속 이어간다.
카메라는 [캐릭터]의 움직임을 따라가며 함께 이동해서, 캐릭터가 화면 안에서 비슷한 위치를 유지하도록 연출한다.
배경의 [환경 요소]는 끊김 없이 흘러가고, 처음과 끝이 자연스럽게 이어지는 루프 영상처럼 보이게 한다.
[분위기/속도감]이 느껴지는 짧은 애니메이션 영상.
```

### 실제 사용 예시

<image source="@/05.jpg">스타트 프레임</image>

```txt
선명하고 채도 높은 2D 애니메이션 스타일로 그린 장면이다. 깔끔한 윤곽선과 플랫한 셀 셰이딩, 밝고 쨍한 컬러 팔레트가 특징이다. 바다가 내려다보이는 초록빛 언덕길을 소녀가 롱보드를 타고 내려가는 중이다. 머리카락과 옷자락이 바람에 흩날리고, 보드 바퀴 아래로 흙먼지가 살짝 일어난다. 언덕 아래로 새파란 바다와 새하얀 파도가 펼쳐져 있고, 하늘은 맑고 쨍한 파란색이다. 대비가 강한 밝은 조명, 생동감 있고 경쾌한 분위기. 역동적인 순간을 포착한 정지된 한 장면.
```

```txt
소녀가 롱보드를 타고 바다가 내려다보이는 초록빛 언덕길을 빠른 속도로 내려간다. 카메라는 소녀의 움직임을 따라가며 함께 이동해서, 소녀는 화면 안에서 비슷한 위치를 유지한 채 계속 타는 동작을 이어간다. 머리카락과 옷자락은 강한 바람에 세차게 흩날린다. 소녀 뒤로는 언덕길과 풀, 저 멀리 바다와 파도가 끊김 없이 빠르게 흘러 지나간다. 역동적이고 시원한 속도감이 느껴지는 영상.
```
