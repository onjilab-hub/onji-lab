<callout>
<b>인물·배경 이미지 → 장면·대사 프롬프트 → 영상 생성</b><br />DomoAI 사이트 하나로 대사와 효과음까지 들어간 짧은 드라마를 만들 수 있어요. 이미지와 영상을 한곳에서 만들 수 있어서, 툴을 오가며 파일을 옮길 필요가 없어요.
</callout>

이번 영상은 <b>DomoAI</b>로 만들었어요. 이미지는 <b>릴랙스 모드</b>로 크레딧 걱정 없이 여러 장 뽑아보고, 마음에 드는 인물과 배경만 골라 영상으로 넘겼어요.

이 가이드는 <b>만들고 싶은 장면을 정한 상태</b>에서 시작해요. 캡처는 실제 제작한 화면이고, 프롬프트는 다른 이야기에도 쓸 수 있도록 정리했어요.

초보 분들을 위해 아주 상세하게 기재해두었으니 도움이 되시길 바랍니다!

## 🔗 사용할 사이트

- 👉 [DomoAI 바로가기](https://domoai.app/?via=df69f7)
- 가입 시 30크레딧이 주어지며, 시댄스 2.5 모델(최상위 모델) 기준 4초 영상 1개 생성 가능 or 시댄스 2.0 fast 2개 생성 가능합니다.

### 캐릭터 시트 만들기

주인공마다 <b>캐릭터 시트</b>를 하나씩 만들어요. 전신 앞·옆·뒤와 얼굴 클로즈업이 한 장에 있어야 영상에서 얼굴과 의상이 컷마다 바뀌지 않아요.<br />만들려고 하는 인물의 얼굴을 첨부 후 아래 프롬프트를 넣어도 되고, 텍스트로 특징을 설명해서 생성해도 됩니다.

<b>📋 캐릭터 시트 프롬프트 ① 얼굴 사진을 첨부할 때</b>

```txt
[첨부한 이미지] 속 인물을 참고해서 흰 배경 스튜디오에서 촬영한 캐릭터 시트를 만들어줘.
상단에는 같은 인물의 전신 정면, 측면, 후면 3컷,
하단에는 얼굴 정면, 3/4 각도, 반대쪽 3/4 각도 클로즈업 3컷을 배치한다.
인물은 [나이·성별·헤어·의상].
모든 컷에서 얼굴, 헤어, 의상이 동일하다. 자연스러운 피부 질감의 실사 사진.
```

<b>📋 캐릭터 시트 프롬프트 ② 사진 없이 텍스트로 특징을 설명할 때</b>

첨부할 사진이 없다면, 아래 빈칸만 채워서 넣어주세요. <b>나이 → 성별 → 얼굴 → 헤어 → 체형 → 상의 → 하의 → 신발</b> 순서로 적으면 빠뜨리는 부분 없이 정리돼요.

```txt

인물 설정
- 나이와 성별: [예: 20대 후반 한국인 여성]
- 얼굴: [예: 갸름한 얼굴, 쌍꺼풀 없는 눈, 옅은 주근깨]
- 헤어: [예: 턱선 길이의 검은 단발, 가르마는 오른쪽]
- 체형: [예: 마른 체형, 키 160cm 정도]
- 상의: [예: 베이지색 랩 니트 가디건]

- 분위기: [예: 차분하고 똑 부러지는 신입 사원]
```

### 배경 이미지 만들기

배경은 <b>사람이 없는 빈 공간</b>으로 만들어요. 인물은 캐릭터 시트로 따로 넣기 때문에, 배경에 사람이 있으면 영상에서 인물이 겹칠 수 있어요.

아래 순서로 적으면 원하는 공간이 잘 나와요.

1. <b>어떤 장소인지</b> — 회의실, 고깃집, 동네 카페
2. <b>어디서 바라본 구도인지</b> — 문 앞에서, 테이블 끝에서, 창가 쪽에서
3. <b>무엇이 놓여 있는지</b> — 가구, 소품, 벽과 바닥
4. <b>언제, 어떤 빛인지</b> — 오후 햇살, 저녁 조명, 형광등
5. <b>분위기</b> — 평범한 일상, 긴장감, 따뜻함

<b>📋 배경 프롬프트 기본형</b>

```txt
[장소]를 [바라보는 위치]에서 바라본 세로 9:16 구도의 실사 사진.
[가구와 소품 묘사].
[벽, 바닥, 창문 묘사].
[시간대]의 [빛 묘사]가 공간을 비춘다.
사람은 없고, [분위기] 느낌의 평범한 일상 공간이다.
```

```txt
장면 설정
오후, 한국 회사의 작은 회의실. 팀장과 직원들이 회의 테이블에 둘러앉아 업무 개선 아이디어를 논의하는 팀미팅.

12.0~15.0초 — 뒤늦은 후회
하드 컷.
```
