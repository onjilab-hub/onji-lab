## 0. 시작 전 — Verdent 시작하기

Verdent는 채팅으로 요청하면 AI가 서비스를 만들어주는 AI 코딩(바이브코딩) 툴입니다.

🔗 [Verdent 바로가기](https://www.verdent.ai/?id=701547)

<b>Cloud Agent</b>를 활용하면 브라우저에서 바로 프로젝트를 시작할 수 있고, 간단한 수정은 <b>Eco Mode</b>로 크레딧 소모를 줄이면서 테스트할 수 있습니다.

## POINT 1. 첫 프롬프트 입력하기

먼저 만들고 싶은 서비스를 한 문장으로 설명합니다. 처음부터 완벽한 결과를 기대하기보다 <b>기본 구조를 만드는 용도</b>라고 생각하면 훨씬 편합니다.

```txt
장시간 PC 작업을 하는 사람을 위한 나만의 작은 비서 캐릭터 루틴 앱을 구축하세요. 스트레칭, 눈 쉬기 같은 건강 루틴과 오늘 할 일을 추가·체크할 수 있는 To-do list, 집중 타이머, 완료율 대시보드, 짧은 알림 기능을 포함합니다.
캐릭터는 루틴과 할 일을 완료할 때마다 반응하고 성장하는 느낌을 주며, PC와 모바일에서 모두 보기 좋은 귀엽고 깔끔한 생산성 앱으로 만드세요.
```

## POINT 2. 수정사항은 코드 대신 말로 요청하기

첫 결과물이 만들어지면 원하는 방향을 계속 채팅으로 수정하면 됩니다. 실제로 요청했던 내용입니다.

### 한국어 UI 변경

```txt
웹/앱의 모든 언어를 한국어로 변경해주세요.
```

### 캐릭터 플로팅 위젯

```txt
캐릭터가 앱을 내려도 PC 화면 위에 작은 플로팅 위젯처럼 남아 있도록 구성하고,
알림 시간이 되면 다른 작업 중에도 캐릭터가 나타나 루틴 알림을 보여주게 해주세요.
웹앱 기술상 제한이 있다면 브라우저 알림과 앱 내부 팝업 알림으로 구현해주세요.
```

### 원하는 캐릭터 적용

```txt
업로드한 캐릭터 이미지를 기본 비서 캐릭터로 사용해주세요.
캐릭터의 얼굴, 색상, 비율을 유지하고 앱 전체에서 일관되게 사용해주세요.
```

Verdent 매니저가 아이디어를 정리하고 작업을 나눠 보여주면, 여기서 <b>원하는 내용을 계속 말로 요청하는 방식</b>이라 부담이 훨씬 적었습니다.

## POINT 3. 원하는 기능 계속 추가하기

기본 구조가 만들어졌다면 필요한 기능을 하나씩 추가할 수 있습니다.

- 오늘 할 일(To-do List)
- 집중 타이머
- 완료율 대시보드
- 건강 루틴 체크
- 캐릭터 반응
- 알림 기능

## POINT 4. 완성된 서비스 실행 및 공유하기

서비스가 완성되면 Verdent 매니저의 안내에 따라 아래까지 진행할 수 있습니다.

- 브라우저에서 바로 실행
- 모바일 화면 확인
- GitHub 연결
- Publish
- 공유 링크 생성

실제 동작하는 서비스를 다른 사람에게 공유하는 것도 가능합니다. (API 등 웹사이트 운영에는 실제 비용이 들 수 있습니다)

## 사용하면서 느낀 점

가장 좋았던 부분은 <b>친절한 개발자에게 계속 요청하면서 같이 만드는 느낌</b>이었다는 점입니다. 모르는 부분을 질문하면 쉽게 설명해주고, 원하는 기능을 말하면 어떻게 구현할지 함께 제안해줍니다. 처음 사용하는 사람도 작은 서비스 하나부터 만들어볼 수 있는 툴이라고 느꼈습니다.
