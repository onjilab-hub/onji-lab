## POINT 1. 채팅으로 디자이너에게 요청하듯 작업하기

채팅창에 원하는 내용을 입력하면 AI가 먼저 컨셉안을 제안합니다. 마음에 드는 방향을 선택하면 캔버스에 결과물이 생성되고, 이후 작업 단계도 자연스럽게 이어갈 수 있습니다.

<b>1. 원하는 작업을 요청합니다.</b>

```txt
[세부 카테고리] 카페 브랜드를 만들거야. 브랜드 아이텐티디 가이드를 잡고 싶어. 
```

<image source="@/02.jpg" />

<b>2. 상세 작업 방향을 설명합니다.</b>

```txt
브랜드 이름은 너가 제안해줘. [원하는 의미 or 방향] 를 담아서. 주요 고객층은 [내 브랜드의 세부 타겟]으로 갈게. 주요 제품은 [제품 카테고리] 이야. 참고 레퍼런스는 [000 / 000 / 000 ]  
```

<b>3. 마음에 들지 않는 부분은 채팅으로 바로 수정 요청할 수 있습니다.</b>

<image source="@/03.jpg" />

<b>4. 고정하고 싶은 작업 흐름이 있다면 지정해주세요.</b>

```txt
실 제작전에 컨셉안을 여러개 제안하고 진행해. 내가 컨펌하면 이후 이미지를 제작해줘
```

## POINT 2. 브랜드 키트 설정하기

## POINT 3. 최신 이미지·영상 모델 활용하기

Lovart 안에서 최신 AI 이미지·영상 생성 모델을 활용할 수 있습니다. 이미지 생성 후 영상으로 변환하는 작업까지 한 흐름 안에서 이어갈 수 있어, 여러 툴을 따로 오가지 않아도 됩니다.

<image source="@/07.jpg" />

## POINT 4. 텍스트 & 오브젝트 직접 수정하기

AI가 만든 결과물을 캔버스 안에서 바로 편집할 수 있습니다. 레이어를 분리한 뒤 텍스트나 오브젝트를 개별 선택해 수정합니다. (이미지에 따라 컬러·텍스트·그림자 일관성이 깨지는 경우가 있는데, 그럴 땐 채팅 수정이 더 좋았습니다.)

<image source="@/08.jpg" />

## POINT 5. 다양한 파일 형식으로 내보내기

완성된 결과물은 마우스 오른쪽 클릭 → 추출하기로 용도에 맞게 내보낼 수 있습니다.

- 인스타그램 피드·웹용 이미지 → PNG, JPG
- 포토샵에서 추가 수정할 디자인 → PSD
- 로고·인쇄용 → SVG
- 릴스·쇼츠 영상 → MP4

<image source="@/09.jpg" />

## 정리

Lovart는 로고, 브랜드 키트, 피드 이미지, 광고 배너, 제품 비주얼, 영상 콘텐츠를 하나의 흐름으로 만들 수 있는 AI 디자인 에이전트 툴입니다. 디자인팀 없이 브랜드 콘텐츠를 직접 만들어야 하는 1인 사업자나 작은 브랜드 운영자에게 유용합니다.
