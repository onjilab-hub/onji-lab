<b>제품 이미지 준비 → 공급업체 소싱 → 업체·가격 비교 → 제품 스펙 검증 → 샘플/OEM 문의 → 상품페이지 기획 → 판매 이미지 제작</b>

## 01. 제품 소싱하기

먼저 판매하고 싶은 제품의 이미지를 넣고 <b>Accio 소싱 전문가</b>에게 비슷한 제품과 공급업체를 찾아달라고 요청했습니다.

### 첫 프롬프트

```txt
첨부한 이미지와 동일하거나 유사한 알루미늄 접이식 노트북 거치대를 1688과 Alibaba에서 찾아줘. 판매량, 평점, 공급업체 신뢰도, 재구매율을 기준으로 신뢰할 수 있는 공급업체 5곳을 선정하고, 추천순으로 정렬해 비교표와 엑셀로 정리해줘. 각 업체별로 MOQ, 단가, 배송 조건, 주문 방법, 제품 특장점, 상품 링크, 샘플 문의가 가능한 연락 경로를 포함해줘. 또한 한국까지 들여올 때 발생하는 예상 배송비, 관부가세, 부가세, 인증비 및 기타 부대비용을 모두 반영해 업체별 실제 예상 총원가를 계산하고, 한국 스마트스토어 판매 수수료까지 고려했을 때 이익률 30%가 남는 적정 판매가도 함께 제안해줘.
```

이렇게 요청하면 <b>공급업체 비교 → MOQ → 공급가 → 예상 원가 → 판매가</b>까지 한 번에 정리할 수 있습니다.

### 여기서 끝내지 않고 추가로 확인했어요

처음 나온 결과를 그대로 사용하기보다 실제 상품페이지를 열어보면서 하나씩 확인했습니다. 특히 공급업체를 추천받을 때는 <b>반드시 상품페이지 링크를 함께 요청</b>하는 걸 추천해요. AI가 제품의 소재나 스펙을 비슷한 모델과 혼동할 수도 있기 때문에, 최종 후보 제품은 실제 상품페이지의 소재·규격·판매 조건을 직접 확인하는 과정이 필요했습니다.

제가 추가로 요청한 내용은 이런 것들이었어요.

- MOQ를 100개로 늘렸을 때의 공급단가 비교
- 1688과 Alibaba의 가격 차이가 발생하는 이유 정리
- 1688 검색 시 상단에 뜨는 제품들이 반영되지 않은 이유
- 제품 소재와 실제 상품페이지 스펙 재확인
- 배송비와 기타 비용까지 포함한 예상 총원가 재계산

### 유용했던 추가 프롬프트

<b>MOQ별 가격을 다시 비교하고 싶을 때</b>

```txt
MOQ를 100개 정도로 늘렸을 때 업체별 공급단가가 얼마인지 다시 비교해줘. 소량 주문 가격과 100개 주문 가격을 함께 보여주고, 이런 조건들을 모두 고려했을 때 추천하는 업체 순서대로 정리해줘. 비교표에는 반드시 실제 상품페이지 링크를 포함해줘.
```

<b>제품 스펙을 다시 검증하고 싶을 때</b>

```txt
추천한 제품의 실제 상품페이지 내용을 다시 확인해줘. 소재, 제품 구조, MOQ, 단가 등 추천 근거가 상품페이지에 실제로 명시되어 있는지 확인하고, 확인할 수 없는 내용은 추정하지 말고 따로 표시해줘.
```

## 04. 판매 이미지 제작 요청

상세페이지 기획이 끝난 뒤에는 <b>Accio 디자인 전문가</b>에게 판매 이미지를 제작해달라고 요청했습니다.

### 처음 사용한 방식

원본 상품페이지와 앞에서 만든 상세페이지 기획안을 함께 전달하고, 각 영역에 필요한 이미지를 만들어달라고 요청했습니다.

### 프롬프트 예시

```txt
아래 원본 상품 페이지의 제품을 소싱해 판매할 예정이야.상세페이지 기획안에 맞춰 각 영역별 판매 이미지를 제작해줘. 텍스트는 내가 추후 직접 편집할 예정이니 이미지에는 텍스트를 넣지 말아줘.먼저 메인 이미지 콘셉트 3가지를 제안하고 각각 예시 이미지를 한 장씩 만들어줘.제품의 형태, 구조, 소재와 컬러는 원본 상품과 동일하게 유지해줘.
```

## 06. 제품이 변형되지 않았는지 꼭 확인

이미지 생성 과정에서 가장 중요하게 확인했던 부분입니다. 처음 만들어진 이미지 중 일부는 분위기는 좋았지만 <b>실제 판매할 제품의 상판 구조, 지지대, 힌지 등 디테일이 다른 제품처럼 변형</b>되어 있었습니다.<br />이럴 때는 원본 제품 이미지를 다시 기준으로 잡고 수정 요청을 했습니다.

### 수정 프롬프트 예시

```txt
0,0,0 이미지에 판매하려는 실제 제품과 제품 형태가 달라졌어. 첨부한 원본 제품 이미지를 다시 기준으로 사용하고, 제품의 상판 형태, 지지대 구조, 힌지 위치, 하판 형태, 실리콘 패드 등 실제 제품의 구조는 변경하지 말아줘. 배경, 조명, 촬영 구도만 변경하고 제품 자체는 원본과 동일하게 유지해줘.
```

## 07. 소구 포인트마다 다른 연출컷 만들기

한 장의 제품 이미지를 반복해서 사용하는 대신, <b>각 셀링 포인트가 직관적으로 보이는 촬영 구도</b>를 따로 요청했습니다.

예를 들어 쿨링 기능을 설명할 때는 단순한 제품 단독 컷이 아니라 노트북을 실제로 올려놓고 <b>노트북 하판과 거치대 통풍 구조가 보이는 각도</b>로 제작했습니다.

## 제가 써보면서 느낀 활용 팁

### ① 한 번에 모든 걸 시키지 않기

<b>소싱 → 검증 → 업체 컨택 → 상품 기획 → 이미지 제작</b> 순서대로 나눠서 진행하면 각 단계의 결과를 확인하고 수정하기 쉽습니다.

### ② 상품 링크를 꼭 같이 요청하기

소싱 결과를 텍스트만 보고 결정하지 말고 실제 상품페이지를 직접 확인하세요. 특히 소재, MOQ, 가격, 제품 구조처럼 판매에 직접 영향을 주는 정보는 한 번 더 검증하는 걸 추천합니다.

### ③ 첫 결과를 완성본으로 생각하지 않기

결과를 본 뒤 "이 조건을 추가해줘", "이 제품은 제외해줘", "100개 기준으로 다시 계산해줘"처럼 계속 이어서 요청할수록 원하는 결과에 가까워졌습니다.

### ④ 디자인은 제품 일관성을 가장 먼저 체크하기

AI 이미지가 예쁘게 나와도 실제 판매 제품과 형태가 다르면 사용할 수 없습니다. 원본 이미지를 계속 참조시키고, 제품은 유지한 채 <b>배경·구도·조명만 변경</b>하도록 요청하는 게 좋습니다.
