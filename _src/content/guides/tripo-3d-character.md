## 📎 만드는 방법

### 1. 캐릭터 이미지 준비

### 2. 이미지 수정

Tripo → [이미지 생성] → NanoBanana 2 또는 GPT Image 2 선택 → 프롬프트 입력 후 이미지 생성

```txt
전신이미지 만들어줘. 3d 캐릭터 스타일. 정면을 보는 T자 포즈로.
```

Tripo → [HD 모델] → 이미지 업로드 → (1) 모델 생성 → (2) 텍스처 생성
