<callout>
GPT 아스트라로 릴스를 만들며 사용한 <b>작업지시서와 단계별 승인 방법</b>을 담았습니다. 찍어두고 묵혀둔 사진과 영상을 콘텐츠로 만드는 데 도움이 되시길 바랍니다😊
</callout>

이번 시연에서는 구글 포토에 보관한 여행 사진·영상으로 릴스를 만들었습니다. 아래 작업지시서는 여행 후기, 장소 소개, 제품 소개, 일상 기록 등 각자의 콘텐츠에 맞게 바꿔 사용할 수 있습니다.

## 작업 흐름

<b>원본 탐색 → 콘텐츠 주제 선택 → 대본·원본·사용 구간 승인 → 음성·자막·컷 편집 → 초안 검토·수정 → 최종 저장</b>

제가 써보면서 중요하다고 느낀 건 <b>무엇을 맡길지, 어디서 내 승인을 받을지 정하는 것</b>이었어요. 주제와 원본을 먼저 확인하고 편집을 맡기면, 원하는 방향으로 작업을 이어가기 좋았습니다.

## 01. 시작 전에 준비하기

- <b>GPT 준비:</b> 아스트라를 이용할 수 있는 [유료 요금제](https://learn.chatgpt.com/docs/pricing)를 준비하고, 데스크톱 앱의 Work 또는 Codex에서 아스트라를 선택하세요.
- <b>원본 준비:</b> 사진·영상을 한 폴더나 앨범에 모으고, 폴더 위치 또는 구글 포토·드라이브 링크를 준비하세요.
- <b>접근·범위 설정:</b> 사용할 계정에 로그인하고 필요한 폴더 접근을 허용한 뒤, 살펴볼 앨범·날짜·장소를 정하세요.
- <b>Fish Audio 준비:</b> [Fish Audio](https://fish.audio/)는 글을 AI 목소리로 읽어주는 음성 제작 사이트예요. <b>미리 회원가입하고 원하는 목소리를 골라, AI에게 지정할 수 있도록 목소리 이름이나 링크를 준비해 주세요.</b> 현재는 무료 제공량 안에서 이용할 수 있어요. 저는 '소심한개구리' 목소리와 속도 1.3배를 사용했어요.
- <b>다른 음성도 가능:</b> 직접 녹음한 파일을 쓰거나, 음성 생성 도구가 연결된 GPT에 제작을 맡길 수 있어요. 도구 연결과 추가 비용은 확인해 주세요.
- <b>영상 조건 정하기:</b> 길이·말투·참고 영상·제외할 장면을 적으세요. 처음이라면 '20~30초, 편안한 후기 말투'로 시작하고 나머지는 추천받아도 돼요.
- <b>시작 전 확인:</b> AI에게 "원본을 열 수 있는지, 영상 편집과 음성 파일 생성이 가능한지 확인하고 필요한 준비를 알려줘"라고 먼저 요청하세요.

구글 포토·드라이브를 사용한다면 원본을 열람할 수 있도록 로그인·연결을 준비해 주세요. 자료 접근이나 편집에 필요한 연결은 사용 중인 AI에서 먼저 확인하면 됩니다.

## 02. 아스트라 선택 후 릴스 작업지시 프롬프트 입력하기

1. <b>ChatGPT 웹 또는 데스크톱 앱에서 Work를 열고 새 대화를 시작하세요.</b>
2. <b>입력창 아래 모델 선택 메뉴에서 'GPT-6 Astra(아스트라)'를 선택하세요.</b> 저는 <b>Astra - Extra High</b>로 작업했어요.
3. 아래 프롬프트를 전체 복사한 뒤 <b>기본 정보의 대괄호 부분만 내 상황에 맞게 바꿔</b> 입력하세요.

처음에는 원본 위치와 탐색 범위부터 채우고, 나머지 조건은 제안받으며 정해도 됩니다. 내 컴퓨터 폴더를 직접 탐색하며 작업하려면 데스크톱 앱에서 시작하는 것을 권장해요.

### 복사용 프롬프트

```txt
내 사진과 영상으로 릴스·쇼츠를 만들어줘. 원본 탐색부터 기획, 편집, 수정까지 진행하되 아래 승인 순서를 지켜줘.

[기본 정보]
- 원본 위치: [구글 포토·드라이브 링크 / 내 컴퓨터 폴더 경로]
- 탐색 범위: [앨범 / 날짜 / 장소 / 폴더]
- 콘텐츠 목적: [여행 후기 / 장소 소개 / 제품 소개 / 일상 기록 / 추천받기]
- 시청 대상: [예: 하와이 여행을 준비하는 사람]
- 원하는 길이: [기본 20~30초]
- 말투와 분위기: [예: 친구에게 추천하듯 편안한 후기]
- 참고 영상: [링크·첨부 파일 / 없음]
- 음성: [내 녹음 / AI 서비스·목소리·속도 / 추천받기 / 없음]
- 제외할 소재: [예: 얼굴이 드러나는 장면, 아이, 차량 번호 / 없음]

정하지 않은 항목은 원본과 목적에 맞게 제안하고, 작업에 꼭 필요한 질문만 묶어서 물어봐줘.

[작업 순서]
1. 원본 탐색 → 주제 선택
원본을 장소·활동·장면별로 살펴보고, 실제 소스로 만들 수 있는 주제 3개를 제안해줘. 각 후보에 제목, 첫 문장, 대표 원본 미리보기, 추천 이유를 담아줘. 라이브 사진은 영상으로 활용 가능한지도 확인하고, 어디까지 탐색했는지 알려줘.

2. 대본·원본 검토 → 내 승인
내가 주제를 고르면 필요한 원본을 다운로드해서 폴더로 정리해줘. 컷별로 대사·자막, 원본 미리보기·파일명, 사용할 시간 구간, 선정 이유·화면 구도를 함께 보여줘. 목소리와 음악도 이 단계에서 제안하고, 내 승인을 받은 뒤 제작해줘.

3. 편집 → 초안 검토
승인한 대본과 원본으로 음성·자막·컷 편집을 진행하고, 재생 가능한 초안을 보여줘.

4. 수정 → 최종 저장
내 수정 요청을 반영하고 바뀐 부분을 간단히 알려줘. 새 원본이나 승인 범위 밖의 구간이 필요하면 변경 후보를 먼저 보여줘.

[편집 기준]
- 세로 9:16, 1080×1920
- 첫 화면과 첫 문장에 볼 이유를 담기
- 내가 제공한 정보와 원본을 바탕으로 쓰고, 없는 경험이나 사실은 만들지 않기
- 전체 풍경·행동·디테일을 다양하게 구성하고 비슷한 장면의 반복 줄이기
- 실제 영상의 움직임을 우선 활용하고, 사진에는 자연스러운 확대·이동 적용
- 과도한 흔들림과 빠른 전환을 피하고, 장면과 대사에 맞게 속도 조절
- 주요 대상이 잘리지 않게 구도를 잡고, 화면 비율이 맞지 않으면 검토 단계에서 처리 방법 제안
- 자막은 가운데 읽기 쉬운 한 줄, 끝 마침표 없이
- 자막 한 마디당 한 화면을 기본으로, 컷과 자막 전환을 해당 문장의 음성 시작에 맞추기
- 음성이 잘리거나 연결이 끊기지 않게 확인
- 음악은 목소리를 가리지 않게 조절하고, 사용 조건을 확인할 수 있는 음원 활용
- 참고 영상이 있다면 움직임·속도·흐름을 내 원본에 맞게 반영

[최종 결과물]
- 자막 있는 완성본 MP4
- 자막 없는 영상 MP4
- 최종 대본과 컷별 원본·사용 구간 목록
- 원본과 완성본이 저장된 폴더 위치

원본은 수정하거나 덮어쓰지 말고 별도로 보관해줘. 최종 저장 전 화면·자막·음성·재생 오류를 확인해줘.

접근할 수 없는 자료나 필요한 앱 연결이 있으면 알려줘. 추가 결제, AI 이미지·영상 생성, 외부 업로드는 별도 승인받아줘.

우선 원본을 살펴보고 주제 3개를 제안한 뒤, 내 선택을 기다려줘.
```

## 03. 주제와 원본을 확인한 뒤 승인하기

AI가 제안한 주제 중 하나를 고르면 대본과 컷별 원본을 검토합니다. <b>대사와 장면이 맞는지, 사용할 구간이 적절한지, 제외하고 싶은 인물이나 장면이 없는지</b> 확인한 뒤 편집을 진행하세요.

## 04. 초안을 보고 말로 수정하기

완성된 초안을 보고 바꾸고 싶은 부분을 구체적으로 요청하세요. 수정할 컷이나 문장을 짚어주고, 유지할 부분도 함께 말하면 원하는 방향을 전달하기 쉽습니다.

### 장면이 비슷하게 반복될 때

```txt
전체 흐름은 유지하고, 3번 컷을 다른 풍경으로 바꾸고 싶어. 대체 원본 후보와 사용할 구간부터 보여줘.
```

### 음성과 화면이 어긋날 때

```txt
각 문장의 음성이 시작되는 시점에 컷과 자막을 맞춰줘. 음성의 끝소리가 잘리거나 다음 문장으로 넘어가지 않는지도 확인해줘.
```

### 전환이 너무 빠를 때

```txt
자막 한 마디당 한 화면으로 정리해줘. 풍경을 보여주는 컷은 조금 여유 있게 보여주고, 불필요한 전환 효과는 줄여줘.
```

## 05. 최종본 저장하기

자막, 음성 연결, 장면 전환을 확인한 뒤 최종본을 저장합니다. <b>자막 없는 영상도 함께 받아두면 편집툴에서 세부 작업을 이어갈 수 있어요.</b>

## 제가 시연에서 사용한 설정

- <b>원본:</b> 구글 포토에 보관한 하와이 여행 사진·영상
- <b>콘텐츠:</b> 쿠알로아 랜치 UTV 체험, 카일루아 비치 소개
- <b>음성:</b> Fish Audio '소심한개구리', 속도 1.3배
- <b>화면:</b> 실제 촬영 영상의 움직임 우선, 가운데 한 줄 자막, 해당 문장의 음성 시작에 컷 전환

위 설정은 시연에서 사용한 예시입니다. 목소리와 속도, 자막 위치 등은 본인의 콘텐츠에 맞게 바꿔 사용하세요.

원본을 고르고 편집 방향을 정하는 과정까지 하나의 작업 흐름으로 만들어보세요. 다음 콘텐츠를 만들 때도 원본 위치와 기본 정보만 바꿔 같은 순서로 맡길 수 있습니다😊
