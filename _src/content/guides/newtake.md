## 전체 제작 흐름

1. 레퍼런스 이미지 등록
2. 이미지 1장을 4컷 스토리보드로 확장 (선택)
3. 스토리보드를 참고해 영상 생성
4. 수정할 구간 선택
5. 해당 구간만 리메이크
6. 결과 비교 후 최종 영상 선택

## STEP 1. 프로젝트 생성 — 영상 주인공으로 사용할 이미지 올리기

먼저 영상에 사용할 캐릭터이미지를 보드에 추가합니다.

캐릭터의 외형을 여러 장면에서 일관되게 유지하려면, 단일 이미지보다 다양한 각도가 담긴 캐릭터 시트를 사용하는 것이 좋습니다. 캐릭터 이미지가 한 장뿐이라면 아래 두 가지 방법으로 캐릭터 시트를 만들어주세요.

### 캐릭터 시트 만들기 (1) — 프롬프트로 생성하기

캐릭터 이미지를 첨부하고 아래 프롬프트를 입력합니다. 인물이라면 레퍼런스 이미지를 여러 장 첨부해주세요.

<b>인물 캐릭터 시트 생성 프롬프트</b>

```txt
첨부한 사진 속 인물을 기반으로 실사 인물 캐릭터 시트를 만들어주세요.

원본 인물의 얼굴형, 이마와 턱의 비율, 눈의 크기와 간격, 눈매, 코의 길이와 형태, 입술 모양, 광대, 헤어라인, 귀의 위치와 검정 단발 헤어를 모든 각도에서 정확히 유지해주세요.

얼굴을 예쁘게 재해석하거나 다른 사람처럼 바꾸지 말고, 원본 인물의 자연스러운 비대칭과 실제 피부 질감까지 유지합니다. AI 미인형 얼굴, 성형한 듯한 변화, 큰 눈, 갸름한 턱, 높은 코, 플라스틱 피부 표현은 금지합니다.

정면, 왼쪽 45도, 오른쪽 45도, 왼쪽 옆면, 오른쪽 옆면, 뒷면의 상반신 모습을 한 이미지 안에 동일한 크기로 배치해주세요.

모든 각도에서 동일한 인물, 동일한 헤어스타일, 동일한 의상, 동일한 액세서리와 체형을 유지합니다. 표정은 모두 편안한 무표정, 시선은 얼굴 방향과 일치하도록 표현해주세요.

동일한 카메라 거리와 조명, 색감으로 촬영한 스튜디오 레퍼런스 시트 형식. 흰색 배경, 선명한 얼굴 디테일, 인물끼리 겹치거나 잘리지 않게 배치. 화면 안에는 글자를 넣지 않습니다.
```

## STEP 2. 이미지 1장을 4컷 스토리보드로 확장하기

레퍼런스 이미지를 연결한 뒤, 만들고 싶은 스토리를 입력해 4컷 그리드로 확장합니다.<br />이번 영상에서는 '늦잠을 자서 회사에 지각한 직장인'의 상황을 만들었습니다.

<image source="@/02.jpg" />

<image source="@/03.jpg" />

### 실제 사용한 4컷 스토리보드 프롬프트

```txt
[캐릭터시트] 를 주체로 [장면이미지] 장면의 다음 장면 스토리 보드를 만들어주세요.
1. 알람을 끄고 다시 잠든 상황.
2. 눈을 뜨고 핸드폰을 확인하며 놀람
3. 회사에 지각해서 눈치보며 자리로 감
4. 자리에 조용히 앉음

모든 장면에서 동일한 인물의 얼굴형, 눈·코·입, 검정 단발 헤어와 체형을 유지해주세요.
집에서는 흰색 반팔 티셔츠의 편안한 잠옷 차림, 회사에서는 흰 셔츠와 검정 재킷을 입은 단정한 오피스룩을 착용합니다.

iPhone으로 촬영한 자연스러운 일상 브이로그 스타일로 표현해주세요. 광고처럼 과도하게 연출된 느낌보다 실제 직장인의 아침을 기록한 듯한 현실적인 분위기로 제작합니다.
```

## STEP 3. 스토리보드로 영상 생성하기

완성된 4컷 스토리보드를 참고 이미지로 연결하고, 영상의 길이와 장면별 동작을 입력합니다.

이번 영상은 4개의 상황을 총 6초의 빠른 컷으로 구성했습니다.

### 실제 사용한 영상 프롬프트

```txt
첨부한 4컷 스토리보드의 인물, 의상, 배경과 장면 구도를 참고해 알람을 끄고 다시 잠든 인물이 늦잠을 자고 회사에 지각하는 상황을 총 6초의 빠른 일상 브이로그 영상으로 만들어주세요.

#인물

[캐릭터시트] 속 인물을 주체로, 얼굴형과 눈·코·입, 검정 단발 헤어, 체형을 모든 장면에서 동일하게 유지합니다. 움직이거나 장면이 전환될 때도 다른 인물로 변형되지 않도록 합니다.

집에서는 흰색 반팔 티셔츠의 편안한 잠옷 차림, 회사에서는 흰 셔츠와 검정 재킷의 단정한 오피스룩을 착용합니다. 회사 장면에서는 검정 숄더백을 한쪽 어깨에 멘 상태를 유지합니다.

#배경

아침: 부드러운 햇빛이 들어오는 작은 오피스텔 침실. 흰색 침구와 생활감 있는 침대.

회사: 모니터와 사무용 의자가 놓인 현실적인 오픈형 사무실. 동료들은 배경에 흐릿하게만 보이고 얼굴은 선명하게 노출하지 않습니다.

#장면

0.0~1.2초

침대에 누워 있던 인물이 눈을 제대로 뜨지 않은 채 한 손을 뻗어 스마트폰 알람을 끕니다. 곧바로 이불을 끌어당겨 덮고 옆으로 돌아누워 다시 잠듭니다.

1.2~2.7초

짧은 타임 점프와 함께 방 안의 햇빛이 조금 더 밝아집니다. 인물이 갑자기 눈을 뜨고 스마트폰을 집어 시간을 확인합니다. 화면을 본 순간 눈이 커지고 입을 살짝 벌리며 크게 놀랍니다.

2.7~4.6초

빠른 점프컷으로 회사 장면으로 전환됩니다. 오피스룩을 입고 검정 숄더백을 멘 인물이 몸을 살짝 움츠린 채 사무실 안으로 들어옵니다. 주변의 눈치를 보며 좌우를 흘끗 살피고 자기 자리로 빠르게 이동합니다.

4.6~6.0초

인물이 자기 자리에 도착해 숄더백을 어깨에서 조심스럽게 내립니다. 소리가 나지 않게 의자를 당겨 빠르게 앉은 뒤, 아무 일도 없었던 것처럼 모니터를 바라봅니다.

#카메라

iPhone으로 촬영한 현실적인 일상 브이로그 스타일. 인물 가까이에서 관찰하듯 촬영하며 살짝 흔들리는 자연스러운 핸드헬드 느낌을 사용합니다. 자동 초점을 사용하고 1~1.5초 간격의 빠른 점프컷으로 구성합니다.

#사운드

아이폰 알람 소리, 침구가 바스락거리는 소리, 짧은 시간 경과 효과음, 빠른 발걸음, 가방 끈과 의자가 움직이는 소리, 잔잔한 사무실 생활 소음.

#금지

색보정, 필름 룩, 시네마틱 룩, 뷰티 필터, CG 질감, 과장된 표정과 슬로모션을 사용하지 않습니다.

화면 내 텍스트, 자막, 이모지, 스티커, 로고, 워터마크를 생성하지 않습니다.

인물의 얼굴과 헤어스타일 변형, 집과 회사 의상 혼합, 숄더백이 장면 중간에 사라지는 현상을 금지합니다.
```

## STEP 4. 원하는 구간만 선택해 리메이크하기

생성된 영상에서 마음에 들지 않는 구간을 선택한 뒤, 바꾸고 싶은 내용만 입력합니다.<br />이때 중요한 점은 '바꿀 내용'뿐 아니라 '유지할 내용'도 함께 적는 것입니다.

<image source="@/04.jpg" />

<image source="@/05.jpg" />

### 구간 리메이크 프롬프트 기본 구조

```txt
{{원본 영상}}의 {{수정할 구간}}을 아래 내용으로 리메이크해주세요.

[변경할 내용]
선택한 구간에서 변경할 인물의 행동, 표정, 배경과 장면 흐름을 작성합니다.

[유지할 내용]
선택 구간 앞뒤의 장면은 수정하지 않습니다.
원본 영상의 전체 길이, 화면 비율, 화질, 인물, 의상, 배경, 카메라 구도, 색감, 조명과 편집 리듬을 유지합니다.

[금지할 내용]
새로운 인물이나 소품을 추가하지 않습니다.
인물의 얼굴, 헤어스타일과 체형을 변형하지 않습니다.
선택한 구간 외의 장면은 변경하지 않습니다.
```

### 실제 사용한 구간 리메이크 프롬프트

수정하고 싶은 영역은 새롭게 작성하고, 유지하고 싶은 영역은 기존 영상 프롬프트와 동일하게 작성합니다.

```txt
[원본 영상]에서 선택한 구간을 아래 내용으로 리메이크해주세요.

알람을 끈 직후부터 회사에 지각해 자리에 앉는 장면까지, 빠른 일상 브이로그로 구성합니다.

기존 영상과 동일한 인물 [캐릭터시트] 의 얼굴형, 눈·코·입, 검은색 단발머리와 체형을 정확히 유지합니다. 집에서는 기존 잠옷, 회사에서는 기존 오피스룩를 유지합니다. 오피스텔 침실과 회사 공간 역시 원본의 배경 구조와 분위기를 그대로 이어갑니다.

0.0초~1.5초 (출근)
갈색 말티즈 강아지를 품에 안은채 집 문을 나선다.
이 장면부터 오피스룩: 와이드 슬랙스, 반팔 브이넥 블라우스. 단정하지만 스타일리시함.
바쁘게 문을 닫고 나가며 품에는 강아지, 출근하는 직장인의 분주한 느낌.
사운드: 문 여닫는 소리, 발걸음 소리.

1.5~3.0초 (회사)

빠른 점프컷으로 회사 장면으로 전환합니다. 인물은 흰 셔츠와 검정 재킷의 기존 오피스룩을 입고 검정 숄더백을 한쪽 어깨에 메고 있습니다.

지각한 듯 몸을 작게 움츠리고 좌우를 흘끗 살피며 빠른 걸음으로 자기 자리로 향합니다.

3.0초~마지막

인물이 숄더백을 조심스럽게 내려놓고 의자를 당겨 최대한 소리 나지 않게 자리에 앉습니다. 아무 일도 없었던 것처럼 자세를 바로잡고 모니터를 바라봅니다.

선택 구간 앞뒤의 기존 장면은 수정하지 않습니다.

원본 영상의 전체 길이, 화면 비율, 화질, iPhone 촬영 질감, 카메라 구도, 색감, 조명과 편집 리듬을 유지하며 선택한 구간만 교체합니다.

기존 영상과 동일한 인물의 얼굴형, 눈·코·입, 검정 단발머리와 체형을 정확히 유지합니다. 집에서는 기존 잠옷, 회사에서는 기존 오피스룩과 검정 숄더백을 유지합니다.

화면 내 텍스트, 자막, 로고, 워터마크와 새로운 인물을 생성하지 않습니다. 얼굴과 헤어스타일 변형, 의상 혼합, 과도한 슬로모션, 시네마틱 룩, 뷰티 필터와 과장된 특수효과를 사용하지 않습니다.
```

## 구간 리메이크할 때 꼭 적어야 하는 것

### 1. 수정 범위

어디서부터 어디까지 바꿀지 선택하고, 해당 구간 안의 시간별 행동을 나눠주세요.

### 2. 변경할 행동

'당황한다'보다 '스마트폰을 확인한 뒤 눈을 크게 뜨고 침대에서 빠르게 일어난다'처럼 동작이 보이도록 작성해주세요.

### 3. 유지할 요소

다음 요소들은 그대로 유지해달라고 명확하게 적어주는 것이 좋습니다.

- 인물 얼굴과 헤어스타일
- 기존 의상과 소품
- 배경 구조
- 카메라 구도
- 영상 색감과 조명
- 전체 편집 리듬
- 선택 구간의 앞뒤 장면

### 4. 생성하지 않을 요소

원하지 않는 변화도 함께 적어주세요.

- 새로운 인물 추가 금지
- 얼굴 변형 금지
- 의상 혼합 금지
- 화면 내 텍스트 생성 금지
- 과한 슬로모션과 특수효과 금지

도움이 되셨다면 저장해두고, 다음 AI 영상 제작에도 활용해보세요😊
