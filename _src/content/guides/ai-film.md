<callout>
<b>이야기 한 줄 → 스토리 → 인물·배경 → 장면별 영상</b><br />AI에이전트로 짧은 드라마를 만들어볼 수 있어요. 처음부터 대본과 영상 프롬프트를 직접 짜지 않아도, AI가 제안하는 내용을 보면서 원하는 방향으로 만들어갈 수 있어요.
</callout>

드라마처럼 이야기가 이어지는 영상은 인물의 외형부터 대사, 장면 연결까지 신경 쓸 게 많잖아요. 저는 이번 영상에서 <b>영상 제작 AI 에이전트인 Buzzy</b>를 활용해봤어요.<br />요즘 영상 플랫폼이 정말 다양하니 이미 사용 중인 생성형 AI플랫폼에 AI에이전트 기능이 있다면 그걸 사용하셔도 괜찮습니다.

이 가이드는 <b>만들고 싶은 짧은 이야기만 정한 상태</b>에서 시작해요. 처음에 아래 요청문으로 이야기를 입력한 뒤에는, <b>AI가 제시하는 다음 단계 버튼을 클릭하며 진행해주세요.</b> 결과에서 바꾸고 싶은 부분이 있을 때만 한국어로 수정 요청을 보내면 돼요. 캡처는 실제 제작한 프로젝트 화면이고, 요청문은 다른 이야기에도 쓸 수 있도록 정리했어요.

## ✅ 시작 전 준비물

1. 영상 AI에이전트
2. 만들고 싶은 이야기 한 줄
3. 주인공 캐릭터시트 (선택)
4. 의상, 배경 참고이미지 (선택)

## ✅ 제작 순서 한눈에 보기

| 단계 | 할 일 |
| --- | --- |
| STEP 1 | AI Film 선택 → 이야기 한 줄 입력 |
| STEP 2 | AI가 확장한 스크립트 확인·수정 |
| STEP 3 | 다음 단계 클릭 → 인물·배경 이미지 확인 |
| STEP 4 | 다음 단계 클릭 → AI가 만든 영상 프롬프트 확인 |
| STEP 5 | 클립 생성 버튼 클릭 → 영상 확인 |
| STEP 6 | 영상 합치기 · 배경음악 선택 |
| STEP 7 | 타이틀 이미지 만들기 · 선택 |
| STEP 8 | 인물과 목소리를 이어서 후속편 만들기 · 선택 |

## STEP 1. AI Film 선택 → 이야기 한 줄 입력하기

<image source="@/01.jpg">입력창에 AI Film이 선택된 화면이에요. 여기에 만들고 싶은 이야기를 입력해요.</image>

1. 👉 [Buzzy 바로가기](https://www.buzzy.now/)에 접속해 로그인
2. 입력창 아래의 <b>AI Film</b> 선택 — <b>Skill</b> 메뉴에서도 선택할 수 있어요
3. 아래 요청문을 복사하고, [만들고 싶은 이야기 한두 문장]만 내 주제로 바꾸기
4. 입력창에 붙여넣고 보내기

<b>📋 첫 스토리 요청문</b>

```txt
AI Film 스킬로 짧은 드라마를 만들고 싶어.

주제: [만들고 싶은 이야기 한두 문장]

이 주제에 어울리는 장르, 인물 관계, 배경과 갈등을 정리하고,
한국어 대사와 장면이 포함된 첫 편 스크립트로 확장해줘.

릴스용 세로 9:16, 20초 내외로 구성해줘.
처음 몇 초 안에 상황이 이해되고,
마지막에는 다음 장면이 궁금해지는 이야기였으면 좋겠어.
시간별 대사, 인물의 행동과 화면 구도를 함께 작성해줘.

먼저 스크립트를 보여주고,
내가 확인하거나 수정한 뒤 인물·배경 이미지와 영상 제작을 단계별로 진행해줘.
```

<b>주제 예시:</b> 매일 엘리베이터에서 마주치는 두 사람. 서로 관심이 있지만 말을 못 하던 중, 한 사람이 이사를 가게 된다.

장르나 결말이 아직 없다면 Buzzy에 함께 제안해달라고 하거나, GPT·Claude에서 먼저 정해도 돼요.

<callout>
<b>한국어 요청이 이상하게 바뀐다면?</b><br />브라우저 자동 번역을 끄고, 영어 화면에서 한국어로 입력해보세요. 저는 이 방법으로 한국어 요청과 결과물을 주고받았어요.
</callout>

## STEP 2. AI가 확장한 스크립트 확인·수정하기

<image source="@/02.jpg">이야기를 설명하면 오른쪽 작업 화면에 스토리와 장면 구성이 만들어져요.</image>

1. <b>Main Story</b>에서 인물 관계와 전체 이야기 흐름 읽기
2. <b>Chapter</b>에서 시간별 대사·행동·화면 구도 확인하기
3. 마음에 들면 <b>다음 단계 버튼을 눌러 인물·배경 제작</b>으로 넘어가기

💡 처음에는 <b>인물 2명·장소 1개</b>로 시작해보세요. 이야기와 장면을 이어가기 한결 쉬워요.

## STEP 3. 다음 단계 클릭 → 인물·배경 이미지 확인하기

<image source="@/03.jpg">캐릭터시트와 의상 참고이미지를 사용해 여성 주인공의 모습을 정리한 화면이에요.</image>

1. <b>Continue generating character and background images</b> 버튼 클릭
2. AI가 만든 <b>인물·의상·배경 이미지</b> 확인하기
3. 마음에 들면 <b>영상 제작으로 넘어가는 다음 단계</b> 선택하기

💬 준비한 캐릭터시트·의상·배경 이미지가 있다면 생성 전에 첨부해주세요. 수정할 부분이 있을 때만 한국어로 요청하면 돼요.

## STEP 4. 다음 단계 클릭 → AI가 만든 영상 프롬프트 확인하기

<image source="@/04.jpg">다음 단계 버튼을 누른 뒤의 화면이에요. 채팅에는 선택한 내용이 메시지로 남고, AI가 장면별 Video Prompt를 만들어줘요.</image>

1. <b>proceed directly to generating video prompts</b> 버튼 클릭
2. AI가 자동으로 작성한 <b>Video Prompt</b>에서 대사·행동·구도 확인하기
3. 마음에 들면 <b>클립 생성 단계</b>로 진행하기

## STEP 5. 클립 생성 버튼 클릭 → 영상 확인하기

<image source="@/05.jpg">장면별 영상이 Long Video 카드로 생성돼요. 예시 프로젝트의 1화는 10초와 8초 클립으로 나뉘었어요.</image>

1. <b>generate the clips</b> 버튼 클릭
2. 생성된 <b>Long Video</b> 카드를 눌러 각 클립 재생하기
3. 마음에 들면 <b>영상 합치기 단계</b>로 진행하기

💬 수정할 곳이 있을 때만 <b>클립 이름 + 바꿀 부분</b>을 지정해 요청해주세요.

## STEP 6. 영상 합치기 · 배경음악 선택

<image source="@/06.jpg">클립을 합친 뒤 Final Video가 만들어진 화면이에요. 예시 프로젝트에서는 18초 영상으로 합쳤어요.</image>

1. 합칠 클립과 <b>이야기 순서</b> 확인하기
2. 음악을 넣으려면 <b>Merge with BGM</b>, 빼려면 <b>Merge without BGM</b> 선택하기
3. 완성된 <b>Final Video</b>를 재생해 장면 연결과 대사 음량 확인하기

## STEP 7. 타이틀 이미지 만들기 · 선택

<image source="@/07.jpg">글자 스타일과 색상, 배경 장식을 바꾸며 타이틀을 수정한 작업 화면이에요.</image>

1. <b>드라마 제목</b> 정하기 — 아직 없다면 아래 '제목 후보 요청' 활용
2. 확정한 <b>주인공·배경</b>으로 타이틀 이미지 요청하기
3. 원하는 서체가 있으면 <b>참고이미지</b>를 넣고 색상·배치 수정하기
4. 완성한 이미지를 <b>썸네일</b>로 쓰거나, 최종 편집할 때 영상 앞에 넣기

<toggle>
💬 제목이 아직 없다면 · 제목 후보 요청

```txt
지금 만든 스토리에 어울리는 드라마 제목과 1화 제목을 각각 5개씩 제안해줘.
인물 관계와 핵심 상황이 짧게 전달되고, 다음 이야기가 궁금해지는 제목이면 좋겠어.
```
</toggle>

<toggle>
🎨 서체·색상·장식 수정 예시

참고이미지에서 <b>서체 느낌만</b> 가져오도록 요청해요. 아래 색상은 원하는 조합으로 바꿔주세요.

```txt
첨부한 이미지에서는 타이틀의 서체 느낌만 참고해줘.
글자 색은 민트와 흰색으로 구성하고, 배경과 구분되도록 가독성을 높여줘.
타이틀 뒤의 반짝이와 연기 장식은 빼고 깔끔하게 정리해줘.
```
</toggle>

## STEP 8. 인물과 목소리를 이어서 후속편 만들기 · 선택

<image source="@/08.jpg">후속편의 스토리를 선택하고, 기존 캐릭터와 새 배경을 연결해 이어서 제작한 화면이에요.</image>

<b>① 같은 프로젝트에서 후속 스토리 요청하기</b>

첫 편을 만든 프로젝트 채팅에 아래처럼 입력해주세요.

<b>📋 후속편 요청문</b>

```txt
다음 편을 만들 건데, 이어지는 스토리 3가지를 제안해줘.
첫 편의 인물과 목소리는 그대로 유지해서 진행할게.
```

<b>② 스토리를 고르고 다음 단계로 진행하기</b>

1. 제안받은 스토리 중 <b>만들고 싶은 번호</b> 선택
2. 첫 편과 같은 방식으로 <b>인물·배경 → 영상 프롬프트 → 클립 생성</b>의 다음 단계 버튼 클릭
3. 생성된 클립을 첫 편과 비교해 듣고, <b>STEP 6</b>처럼 합치기

<b>처음에는 짧은 이야기 하나로 시작해보세요.</b> AI가 만든 스토리와 장면을 보면서 "이 부분은 이렇게 바꿔줘"라고 요청하다 보면, 내가 원하는 드라마에 조금씩 가까워질 거예요.
