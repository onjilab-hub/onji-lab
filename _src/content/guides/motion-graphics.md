tools: Nanobanana Pro, Kling

## ✏️ 프롬프트

### 1. 완성 이미지 (Nanobanana Pro)

```txt
첨부한 레퍼런스 이미지 스타일 유지
텍스트 "onji lab"을
실버 크롬 액체 형태의 3D 오브젝트로 생성

물방울처럼 유기적인 형태,
반사되는 금속 질감,
공중에 떠 있는 구성

밝은 하늘 배경, 자연광, 미니멀 무드
```

### 2. 재질 이미지 (Nanobanana Pro)

```txt
첫 번째 이미지를 완전히 분해해서
글자 형태 없이
실버 액체 물방울로 재구성

크기 다양한 물방울이
공중에 자연스럽게 흩어진 구성

하늘 배경 유지, 자연광, 미니멀 무드
```

### 3. 이미지 2장 → 모션 (Kling)

재질 이미지를 시작 프레임, 완성 이미지를 끝 프레임으로 넣고 아래 프롬프트를 입력합니다.

```txt
chrome liquid droplets floating in the sky.

droplets attract and merge,
forming liquid metal shapes.

smooth morph into text "onji lab".

clean formation, reflective chrome,
soft motion, blue sky reflection
```

## 💡 활용 팁

- 텍스트만 바꾸면 다양한 로고 제작 가능
- 재질(실버, 유리, 젤 등)을 바꾸면 무드 다양화 가능
- 브랜드 키비주얼, 썸네일, 숏폼 콘텐츠에 활용 가능
