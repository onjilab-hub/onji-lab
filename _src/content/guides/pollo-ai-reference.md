## 0. 시작 전 — Pollo AI 접속하기

먼저 Pollo AI에 접속해 로그인합니다. 한국어로 편하게 사용할 수 있도록 화면 언어를 한국어로 설정해 주세요.

🔗 [Pollo AI 바로가기](https://pollo.ai/ko/home)

## 1. 필요한 자료 준비하기

영상 생성 전 아래 자료를 먼저 준비해 주세요.

<image source="@/01.jpg" />

### ① 레퍼런스 영상

새로 만들 영상에서 참고하고 싶은 광고나 영상입니다. 다음 요소를 참고할 수 있어요.

- 전체적인 장면 구성
- 카메라 구도와 움직임
- 컷 전환 속도
- 인물의 동작
- 영상의 분위기와 스타일

### ② 장면 프롬프트

레퍼런스에서 유지할 부분과 새롭게 변경할 내용을 작성합니다.

### ③ 인물·제품 이미지

새 영상에 등장할 인물이나 제품 이미지를 준비합니다. 가능하면 형태가 선명하고 배경이 단순한 이미지를 사용하는 것이 좋아요.

## 2. '레퍼런스 기반 영상 생성' 선택하기

Pollo AI 메인 화면에서 <b>레퍼런스 기반 영상 생성</b>을 선택합니다. 이 기능은 레퍼런스 영상을 참고해 원하는 장면이나 흐름을 새로운 소재로 재구성할 때 활용할 수 있습니다.

## 4. 장면 프롬프트 작성 후 생성

<callout>
아래 프롬프트는 영상 제작에 실제로 사용한 입력본입니다. 파일명과 에셋 ID는 보기 쉽게 `[레퍼런스 영상]`, `[인물 이미지]` 등의 표기로 바꿨습니다. 본인이 업로드한 자료에 맞춰 해당 부분을 변경해 주세요.

### 먼저 업로드한 자료

- `[레퍼런스 영상]`: Meta Ray-Ban AI 글로벌 광고
- `[인물 이미지]`: 한국인 여성 모델
- `[의상 이미지]`: 모델이 착용할 비즈니스 캐주얼 의상
- `[제품 이미지]`: 매트 블랙 AI 스마트 안경
- `[번역 요청 UI 이미지]`: "Hey Meta, start live translation."
- `[번역 중 UI 이미지]`: "Translating…"

### 실제 사용 프롬프트

```txt
[레퍼런스 영상]은 Meta Ray-Ban AI 글로벌 광고입니다.

레퍼런스 영상의 전체적인 장면 흐름과 광고 포인트를 참고해 한국 버전의 AI 스마트 안경 광고를 제작해 주세요.

[기본 설정]

모델:
[인물 이미지] 속 얼굴을 기반으로 한 20대 후반 한국인 여성.
[의상 이미지] 속 의상과 [제품 이미지] 속 매트 블랙 AI 스마트 안경을 착용한다.

제품:
측면 카메라 모듈이 포함된 매트 블랙 컬러의 AI 스마트 안경.
모든 장면에서 안경의 색상, 프레임과 카메라 모듈 형태를 동일하게 유지한다.

배경:
서울 성수동에 있는 유러피안 레스토랑 입구.
따뜻한 골든아워 조명을 사용한다.

연출:
[레퍼런스 영상]의 장면 구성, 카메라 움직임과 편집 리듬을 참고한다.
한국어 대사와 미니멀한 AR 번역 인터페이스를 적용한다.

포맷:
16:9 가로형, 15초.

[장면 구성]

0~3초:

검은색 AI 스마트 안경을 쓴 한국인 여성이 레스토랑 입구로 들어온다.

카메라는 가슴 높이의 미디엄 숏으로 여성을 따라가며, 여성이 레스토랑 안쪽에 있는 친구들을 발견하고 반갑게 미소 짓는 모습을 보여준다.

지나가는 사람 한 명이 카메라 앞을 자연스럽게 스치며 화면에 깊이감을 만든다.

3~6초:

한국인 여성의 시선 방향에 있는 세 명의 외국인 친구들이 다른 언어로 빠르게 대화하고 있다.

친구들은 한국인 여성과 자연스럽게 인사를 나누지만, 곧 다시 외국어로 대화를 이어간다.

여성은 미소를 유지하면서도 대화 내용을 이해하지 못해 잠시 조용히 듣는다.

친구들의 대화 장면과 여성의 반응을 짧게 교차 편집한다.

6~8초:

카메라가 한국인 여성의 얼굴과 AI 스마트 안경을 정면에서 클로즈업한다.

안경의 검은색 프레임과 측면 카메라 모듈이 선명하게 보인다.

여성은 자연스러운 한국어로 낮게 말한다.

"헤이 메타, 이 대화 번역해 줘."

화면 중앙 왼쪽에 작고 미니멀한 반투명 인터페이스가 나타난다.

[번역 요청 UI 이미지]를 참고해 흰색 아이콘과 함께 다음 문구를 표시한다.

"Hey Meta, start live translation."

과장된 홀로그램이나 거대한 그래픽 효과는 사용하지 않는다.

8~13초:

한국인 여성과 세 명의 외국인 친구들이 계속 대화한다.

화면 중앙 왼쪽에 작고 미니멀한 반투명 인터페이스가 나타난다.

[번역 중 UI 이미지]를 참고해 흰색 번역 아이콘과 함께 다음 문구를 표시한다.

"Translating…"

친구 한 명이 외국어로 말하고, 한국어 번역 음성이 자연스럽게 들린다.

"근처에 맛있는 디저트 가게가 있대."

다른 친구가 이어서 말하고, 다음 한국어 번역 음성이 들린다.

"같이 가볼래?"

여성은 대화를 이해한 순간 자연스럽게 웃고 고개를 끄덕인다.

안경의 디자인과 여성의 얼굴 형태는 모든 컷에서 동일하게 유지한다.

13~15초:

한국인 여성이 친구들을 바라보며 밝게 말한다.

"좋아, 같이 가자."

친구들이 웃으며 여성과 함께 레스토랑 안쪽으로 걸어간다.

[전체 스타일]

부드러운 핸드헬드 카메라, 얕은 심도, 자연스러운 인물 움직임과 절제된 연기를 사용한다.

따뜻한 골든 브라운과 아이보리 컬러를 중심으로 세련된 글로벌 테크 브랜드 광고처럼 사실적이고 영화적인 이미지로 표현한다.

배경에는 낮은 레스토랑 대화 소리, 발걸음, 옷이 스치는 소리와 은은한 미니멀 전자 음악을 사용한다.

외국어 대화와 지정된 한국어 대사 외에는 다른 음성이나 내레이션을 추가하지 않는다.

[제외 요소]

과장된 SF 효과, 거대한 홀로그램, 제품 형태 변경, 안경이 사라지는 현상, 인물 얼굴 변경, 추가 인물 생성, 깨진 글자, 자막 오타, 워터마크, 휴대폰 UI는 사용하지 않는다.
```

## 5. 프롬프트 적용 팁

#### 1. 자료 이름을 정확하게 구분해 주세요

```txt
[인물 이미지]는 얼굴과 헤어스타일 참고
[의상 이미지]는 착장 참고
[제품 이미지]는 제품 디자인 참고
```

#### 2. 만들고 싶은 영상이 정해져 있다면, 시간대별로 나눠 작성해 주세요

15초 영상도 `0~3초`, `3~6초`처럼 나누면 장면의 순서와 전환을 더 정확하게 전달할 수 있습니다.

#### 3. 한글 문자는 후편집을 추천해요

아직 한글 문자는 깨져 나오는 경우가 종종 있습니다. UI 또는 장면에 한글 문자가 필요하다면 사용할 한글이 포함된 레퍼런스 이미지를 업로드하고, 자막은 후편집으로 넣어주세요.

#### 4. 레퍼런스는 구조 중심으로 활용해 주세요

장면 흐름, 카메라 움직임과 편집 리듬은 참고하되, 인물·제품·배경·대사·음악은 내 콘텐츠에 맞게 새롭게 구성하는 것을 추천합니다.
